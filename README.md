# 홈페이지 제작 요구사항 정의서·체크리스트 | 홈피나라 실무 문서

홈페이지와 예약·관리 프로그램을 만들 때 발주처와 제작사가 실제로 주고받는 문서를 모아 공개합니다. 요구사항 정의서, 도입 체크리스트, 장애 점검 가이드처럼 "맡기기 전에 정리해 두면 견적과 일정이 정확해지는" 자료들입니다.

만든 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 제작해 왔습니다. 현장에서 부딪힌 것들을 문서로 옮깁니다.

## 문서 목록

### 템플릿
- [홈페이지 제작 요구사항 정의서 템플릿](templates/홈페이지-제작-요구사항-정의서-템플릿.md) — 제작을 맡기기 전에 복사해서 채우는 무료 양식. 개요·목표·기능·콘텐츠 준비·일정까지 11개 항목.

### 도입 체크리스트
- [전자계약 도입 체크리스트](checklists/전자계약-도입-체크리스트.md) — 계약 종류별 확인 항목과 시스템 요건. 전자문서법·전자서명법 조문 근거 포함.
- [그룹웨어 도입 체크리스트](checklists/그룹웨어-도입-체크리스트.md) — 결재선·문서·근태·이관 범위를 정리하는 항목과 구축 방식 비교 기준.
- [재고관리 도입 체크리스트](checklists/재고관리-도입-체크리스트.md) — 품목 단위 정의부터 실사 오차 처리·엑셀 이관까지. 재고자산 평가방법 신고(법인세법 시행령 제74조)와 장부 보존(상법 제33조) 근거 포함.
- [숙박·펜션 실시간 예약 시스템 도입 체크리스트](checklists/숙박예약-도입-체크리스트.md) — 객실·요금 구조부터 중복 예약 방지, 취소 위약금 자동 계산까지. 농어촌민박 신고 요건(농어촌정비법 제86조)과 소비자분쟁해결기준(2024.12.19 개정) 근거 포함.
