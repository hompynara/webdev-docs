# 홈페이지 제작 요구사항 정의서·체크리스트 | 홈피나라 실무 문서

홈페이지와 예약·관리 프로그램을 만들 때 발주처와 제작사가 실제로 주고받는 문서를 모아 공개합니다. 요구사항 정의서, 도입 체크리스트, 장애 점검 가이드처럼 "맡기기 전에 정리해 두면 견적과 일정이 정확해지는" 자료들입니다.

만든 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 제작해 왔습니다. 현장에서 부딪힌 것들을 문서로 옮깁니다.
