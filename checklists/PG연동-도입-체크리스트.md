# PG 연동 도입 체크리스트 — 결제창 확인 절차부터 환불·에스크로·현금영수증·정기결제·해외 결제까지

홈페이지에 카드 결제를 넣으려면 PG(전자지급결제대행)사와 가맹 계약을 맺고, 사이트의 주문 기능과 PG 결제창을 연결해야 합니다. 연동 작업 자체는 PG사가 제공하는 개발 문서대로 진행하면 되지만, 오픈 뒤에 문제가 생기는 지점은 따로 있습니다. **결제 직전에 소비자에게 무엇을 보여 주고 확인시키는가**, **취소·환불을 결제수단마다 어떻게 처리하는가**, 그리고 **계좌이체·가상계좌로 선결제를 받을 때 에스크로와 현금영수증을 어떻게 처리하는가**입니다. 셋 다 전자상거래 등에서의 소비자보호에 관한 법률(이하 전자상거래법)에 직접 연결되어 있어, 연동 전에 회사 쪽에서 결정해 두셔야 합니다.

이 문서는 PG 연동을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. PG 계약 전에 사이트에 갖춰 둘 것

PG사는 가맹 심사 때 사이트에 상품·가격·환불 규정·사업자 정보가 실제로 표시돼 있는지 확인하는 경우가 많습니다. 아래 항목은 PG 심사와 별개로 법정 표시 사항이므로, 결제 연동 전에 사이트에 먼저 넣어 두는 편이 일정이 덜 밀립니다.

| 표시 항목 | 근거 |
| --- | --- |
| 상호, 대표자 성명 | 전자상거래법 제10조 제1항 제1호, 제13조 제1항 제1호 |
| 영업소 주소(소비자 불만을 처리하는 곳 포함), 전화번호, 전자우편주소 | 제10조 제1항 제2호·제3호 |
| 사업자등록번호 | 제10조 제1항 제4호 |
| 사이버몰 이용약관 | 제10조 제1항 제5호 |
| 통신판매업 신고번호와 신고 기관 | 제13조 제1항 제3호 |
| 호스팅서비스 제공자의 상호 | 제10조 제1항 제6호, 시행령 제11조의4 |

통신판매업자는 상호·주소·전화번호·전자우편주소·인터넷 도메인 이름·호스트서버 소재지 등을 신고해야 합니다. 거래 횟수·규모가 공정거래위원회 고시 기준 이하이면 신고하지 않아도 됩니다(제12조 제1항). 신고 대상인지는 고시 기준으로 먼저 확인하십시오.

- [ ] 통신판매업 신고 대상인지 확인했고, 대상이면 신고번호를 받아 두었는가
- [ ] 사이트 하단에 위 표시 항목이 모두 들어 있는가 (호스팅 업체 상호 포함)
- [ ] 이용약관과 교환·반품·환불 규정 페이지가 오픈 전에 완성돼 있는가
- [ ] 사용할 결제수단(카드·계좌이체·가상계좌·간편결제·휴대폰 결제·해외 결제)을 확정했는가
- [ ] 결제수단마다 PG사의 수수료·정산 주기·보증보험 요구 여부를 계약 전에 비교했는가

## 2. 결제수단마다 취소·정산 방식이 다르다

결제수단을 늘리면 결제할 수 있는 고객은 늘지만, 취소·환불 처리 방식도 결제수단 수만큼 늘어납니다. 관리자 기능을 견적에 넣기 전에 결제수단별 처리 방식을 먼저 확인하십시오.

| 결제수단 | 주문 확정 시점 | 취소·환불 처리 | 함께 결정할 것 |
| --- | --- | --- | --- |
| 신용카드 | 승인 즉시 | PG를 통한 승인 취소·부분 취소 | 할부 개월 수 · 부분 취소 허용 여부 |
| 계좌이체 | 이체 완료 즉시 | PG를 통한 취소 또는 계좌 환불 | 현금영수증 발급 방식 (7절) |
| 가상계좌 | 입금 통보가 사이트에 도착한 때 | 카드처럼 승인 취소가 되지 않아 환불 계좌 정보가 필요 | 입금 기한 · 기한 경과 주문 자동 취소 · 에스크로 (6절) |
| 간편결제 | 승인 즉시 | 간편결제사·PG 정책에 따름 | PG 계약에 포함되는지 · 별도 계약인지 |
| 휴대폰 결제 | 승인 즉시 | 결제한 달이 지나면 승인 취소 대신 계좌 환불로 처리하는 PG사가 많음 | 월 한도 · 취소 가능 기간 |
| 해외 카드·PayPal | 승인 즉시 | 결제 통화로 환불, 환율 차이 발생 가능 | 정산 통화 · 출금 환전 수수료 (10절) |

- [ ] 결제수단별 취소 가능 기간과 부분 취소 지원 여부를 PG사에 확인했는가
- [ ] 가상계좌 입금 기한과 기한이 지난 주문의 처리 방식을 결정했는가
- [ ] 가상계좌·휴대폰 결제를 계좌로 환불할 때 환불 계좌를 어떤 방법으로 확인할지 결정했는가
- [ ] 정산 주기와 정산 금액(수수료 차감 후)을 관리자 페이지에서 확인할 수 있는가

## 3. 결제창 직전에 보여 줄 것과 하지 말 것

전자적 대금지급에서 사업자와 PG사 등 전자결제업자는 **재화등의 내용과 종류, 가격, 용역의 제공기간**을 명확히 고지하고 소비자가 확인하는 절차를 마련해야 합니다(전자상거래법 제8조 제2항). 이 확인은 PG사가 마련한 결제창으로 진행하고, **소비자가 직접 선택하기 전에 동의 표시를 미리 해 두면 안 됩니다**(시행령 제9조).

2025년 2월 14일부터는 결제 과정의 설계 방식 자체도 규제 대상입니다(제21조의2 제1항).

| 금지 행위 | 결제 페이지에서 생기는 예 | 근거 |
| --- | --- | --- |
| 가격을 알리는 「첫 화면」에 필수로 내야 하는 총금액 중 일부만 표시 | 상품가만 크게 표시하고 필수 배송비·설치비·수수료를 결제 단계에서 처음 보여 줌 | 제21조의2 제1항 제1호 |
| 다른 상품·가입 청약을 미리 선택된 상태로 제시 | 보험·연장보증·유료 멤버십 체크박스가 처음부터 체크돼 있음 | 같은 항 제2호 |
| 선택 항목 사이에 크기·모양·색깔로 현저한 차이를 두어 특정 항목만 선택할 수 있는 것처럼 오인시킴 | 「추가 구매」 버튼은 크게, 「건너뛰기」는 회색 작은 글씨 | 같은 항 제3호 |
| 이미 내린 선택을 바꾸라고 팝업으로 반복 요구 | 결제 취소를 누를 때마다 할인 팝업 반복 (7일 이상 다시 보지 않기 선택권을 주면 예외) | 같은 항 제5호, 시행령 제27조의2 |

- [ ] 상품 목록·상세 페이지의 가격 표시에 필수 비용이 모두 포함돼 있는가 (총금액 표시가 불가능한 사유가 있으면 그 사유를 알리는가)
- [ ] 결제 직전 주문 요약에 상품 내용·수량·가격·배송비·용역 제공기간이 함께 표시되는가
- [ ] 약관·개인정보 동의와 추가 상품 선택 항목이 미리 체크돼 있지 않은가
- [ ] 「구매」와 「취소·건너뛰기」 선택지의 크기·색깔 차이가 오인을 일으키지 않는가
- [ ] 소비자가 미성년자일 수 있는 상품이면 법정대리인 동의가 없을 때 계약을 취소할 수 있다는 내용을 고지하는가 (제13조 제3항)

## 4. 결제 결과는 서버에서 다시 확인한다

PG 연동에서 가장 흔한 사고는 기능 누락이 아니라 **결제 결과를 브라우저가 보낸 값 그대로 믿는 것**입니다. 결제 완료 후 브라우저가 돌아오는 페이지만으로 주문을 확정하면, 금액을 조작한 요청이나 중간에 끊긴 결제를 구분하지 못합니다.

- [ ] 결제 승인 금액을 사이트 서버에 저장된 주문 금액과 대조한 뒤에 주문을 확정하는가
- [ ] PG사가 서버로 보내는 결제 결과 통보(웹훅·노티)를 받아 처리하는가 — 고객이 결제 직후 창을 닫아도 주문이 확정되는가
- [ ] 같은 결제 통보가 두 번 도착해도 주문이 두 번 처리되지 않는가
- [ ] 결제는 승인됐는데 사이트 주문 처리가 실패한 건을 찾아내는 대사(정산 대조) 절차가 있는가
- [ ] 카드번호를 사이트 서버나 DB에 저장하지 않고 PG 결제창에서만 입력하는가 (정기결제는 PG가 발급하는 빌링키로 처리)
- [ ] 결제가 끝나면 소비자에게 전자문서 등으로 결제 사실을 알리고, 소비자가 결제 관련 자료를 언제든 열람할 수 있는가 (제8조 제3항)
- [ ] PG사에 결제 처리를 맡긴다는 사실과 PG사 이름을 개인정보 처리방침에 공개했는가 (개인정보 보호법 제26조 제2항)

## 5. 환불은 3영업일, 카드 결제는 PG에 취소를 요청한다

소비자는 계약 내용에 관한 서면을 받은 날부터(재화 공급이 더 늦으면 공급받은 날부터) **7일 이내**에 청약을 철회할 수 있습니다(제17조 제1항). 재화가 표시·광고나 계약 내용과 다르면 공급받은 날부터 3개월, 그 사실을 안 날부터 30일 이내에 철회할 수 있습니다(같은 조 제3항).

| 상황 | 사업자가 할 일 | 근거 |
| --- | --- | --- |
| 재화를 공급한 뒤 청약철회 | 재화를 반환받은 날부터 **3영업일 이내** 환급 | 제18조 제2항 제1호 |
| 용역·디지털콘텐츠, 또는 공급 전 청약철회 | 청약철회한 날부터 3영업일 이내 환급 | 제18조 제2항 제2호·제3호 |
| 카드 등으로 결제한 경우 | 지체 없이 결제업자(카드사·PG)에 대금 청구 정지·취소 요청. 이미 대금을 받았으면 결제업자에게 지체 없이 환급하고 소비자에게 알림 | 제18조 제3항 |
| 환급 지연 | 지연기간에 대해 **연 15%** 지연배상금 | 제18조 제2항, 시행령 제21조의3 |
| 선결제 후 품절 등으로 공급 곤란 | 지체 없이 사유를 알리고 대금 지급일부터 3영업일 이내 환급 | 제15조 제2항 |

청약철회 때 반환 비용은 소비자가, 표시·광고와 다르게 이행된 경우의 반환 비용은 통신판매업자가 부담합니다(제18조 제9항·제10항). 청약철회를 이유로 위약금이나 손해배상을 청구할 수 없습니다(같은 조 제9항).

- [ ] 관리자 페이지에서 반품 입고 처리와 PG 승인 취소가 같은 흐름으로 이어지는가
- [ ] 반품 입고일·청약철회일이 기록되고, 환급 기한(3영업일)이 지난 건을 관리자에게 표시하는가
- [ ] 여러 상품 중 일부만 반품할 때 부분 취소 금액이 자동 계산되는가 (배송비 재계산 포함)
- [ ] 청약철회가 제한되는 상품(주문 제작품 등)은 그 사실을 상품 페이지와 결제 전에 명확히 표시하는가 (제17조 제2항·제6항, 시행령 제21조)

## 6. 계좌이체·가상계좌 선결제에는 에스크로 선택권을 둔다

소비자가 재화를 받기 전에 대금을 먼저 내는 **선지급식 통신판매**에서는 소비자가 원하면 **결제대금예치(에스크로)** 또는 소비자피해보상보험계약등을 선택할 수 있다는 사실을 알리고(제13조 제2항 제10호), 소비자가 선택하면 그대로 이용하게 해야 합니다(제24조 제2항). 위반하면 2천만원 이하 과태료 대상입니다(제45조 제3항 제4호).

다만 아래 거래는 이 의무에서 제외됩니다(제24조 제3항).

| 제외되는 거래 | 근거 |
| --- | --- |
| 신용카드로 대금을 지급하는 거래 | 제24조 제3항 제2호 |
| 정보통신망으로 전송되는 재화등, 또는 예치 기관이 배송을 확인할 수 없는 재화등의 거래 | 같은 항 제3호 |
| 일정 기간에 걸쳐 나누어 공급되는 재화등의 거래 | 같은 항 제4호 |
| 공정거래위원회가 고시하는 거래 | 같은 항 제5호 |

실무에서 에스크로가 필요한 경우는 **배송 상품 대금을 계좌이체·가상계좌로 먼저 결제하는 경우**입니다. PG사 대부분이 에스크로를 옵션으로 제공하지만, 배송 정보(택배사·송장번호)를 PG에 등록해야 구매 확정과 정산이 진행되므로 관리자 기능이 달라집니다.

- [ ] 계좌이체·가상계좌 결제 때 에스크로 이용 여부를 소비자가 선택할 수 있는가
- [ ] 에스크로 결제 건은 송장번호를 PG에 자동으로 등록하는가, 관리자가 직접 입력하는가
- [ ] 결제 페이지에 에스크로 가입 사실을 표시하는가 (가입하지 않은 사업자의 표지 사용 금지 — 제24조 제8항·제9항)

## 7. 현금 결제분은 현금영수증 발급까지 설정한다

계좌이체·가상계좌 입금은 현금 거래입니다. 현금영수증가맹점은 소비자가 요청하면 발급을 거부하거나 사실과 다르게 발급할 수 없고(소득세법 제162조의3 제3항), **의무발행업종**(소득세법 시행령 별표 3의3)이면 건당 10만원(부가가치세 포함) 이상은 소비자가 요청하지 않아도 발급해야 합니다(같은 조 제4항). 이때 대금을 받은 날부터 5일 이내에 무기명으로 발급할 수 있습니다(시행령 제210조의3 제13항). 사업자에게 세금계산서·계산서를 발급한 거래는 제외됩니다(같은 조 제4항 단서).

- [ ] 우리 업종이 현금영수증 의무발행업종인지 세무 담당자와 확인했는가
- [ ] 계좌이체·가상계좌 결제 때 PG의 현금영수증 자동 발급을 설정했는가
- [ ] 결제 페이지에서 소득공제용·지출증빙용 선택과 번호 입력이 가능한가
- [ ] 소비자가 번호를 입력하지 않은 의무발행 거래를 무기명(국세청 지정 번호)으로 발급하는가
- [ ] 환불·부분 취소 때 현금영수증도 함께 취소·재발급되는가

## 8. 카드 결제에 두면 안 되는 조건

신용카드가맹점은 **신용카드로 거래한다는 이유로 결제를 거절하거나 카드 회원을 불리하게 대우할 수 없고**(여신전문금융업법 제19조 제1항), **가맹점수수료를 카드 회원에게 부담시킬 수 없습니다**(같은 조 제4항). 둘 다 1년 이하 징역 또는 1천만원 이하 벌금 대상입니다(제70조 제4항 제4호·제5호).

**다른 가맹점의 명의로 카드 거래를 하거나 남의 카드 거래를 대행하는 것**도 금지되며(제19조 제5항 제3호·제5호), 3년 이하 징역 또는 2천만원 이하 벌금 대상입니다(제70조 제3항 제3호·제4호). 계열사나 협력업체의 상품을 우리 사이트에서 우리 상점 ID로 결제하는 구조가 여기에 해당할 수 있습니다.

- [ ] 카드 결제 시 추가 금액을 더하거나 카드 결제를 최소 금액 이상으로 제한하는 설정이 없는가
- [ ] 「현금 결제 시 할인」 문구가 카드 회원을 불리하게 대우하는 표시가 되지 않는지 확인했는가
- [ ] 사이트에서 판매하는 상품이 모두 우리 사업자의 상품인가 (다른 사업자 상품이 섞이면 9절 검토)

## 9. 여러 판매자의 대금을 받아 나눠 주는 구조라면 따로 검토한다

입점 업체 상품을 함께 팔고 대금을 우리가 받아 업체별로 정산해 주는 구조는 단순한 PG 연동이 아닙니다. 다른 사업자 사이 거래의 대가를 받아 정산을 대행하는 업무는 **전자지급결제대행업**으로서 금융위원회 등록 대상이 될 수 있습니다(전자금융거래법 제28조 제2항 제4호).

2026년 12월 17일 시행 개정 전자금융거래법은 전자지급결제대행의 정의를 「제3자 사이에서 이루어지는 재화·용역 대가의 지급이 전자지급수단으로 이루어질 때 그 대가를 수수하고 정산을 대행하는 것」으로 바꾸고, **통신판매중개 등 다른 업무를 하면서 부수적으로 대가를 받아 정산을 대행하는 경우는 제외**합니다(제2조 제19호). 같은 개정에서 등록한 PG사의 정산대상금액을 은행 등을 통해 신탁·예치·지급보증보험으로 외부 관리하도록 하는 규정이 신설됩니다(제25조의4).

통신판매중개자가 되면 전자상거래법상 의무도 달라집니다. 통신판매의 당사자가 아니라는 사실을 미리 고지하고(제20조 제1항), 입점 판매자의 신원정보를 확인해 소비자에게 제공해야 합니다(같은 조 제2항).

- [ ] 사이트에서 다른 사업자의 상품을 판매하는지 확인했는가
- [ ] 그렇다면 PG사의 하위 가맹점(오픈마켓·플랫폼용) 상품으로 계약하는지, 우리가 정산을 대행하는 구조인지 결정했는가
- [ ] 정산을 대행하는 구조라면 전자지급결제대행업 등록 대상인지 법률 검토를 받았는가 (2026.12.17 시행 조문 기준)
- [ ] 통신판매중개자로서의 고지·신원정보 제공 항목을 사이트에 반영했는가

## 10. 정기결제는 증액·유료 전환 30일 전에 동의를 거친다

구독·월 이용료처럼 정기결제를 받으면, 결제 금액이 **증액되거나 무료 이용 후 유료로 전환될 때** 그 **30일 전까지** 증액·전환 일시, 변동 전후 가격, 결제방법에 대해 소비자 동의를 거치고, 취소·해지 조건과 방법을 고지해야 합니다(제13조 제6항, 시행령 제20조의2). 해지 절차를 가입 절차보다 복잡하게 만들거나 가입과 다른 방법으로만 해지하게 하는 것도 금지됩니다(제21조의2 제1항 제4호). 둘 다 1천만원 이하 과태료 대상입니다(제45조 제4항 제5호의2·제7호).

- [ ] 카드번호 대신 PG 빌링키로 정기결제를 처리하는가
- [ ] 무료 체험 종료일과 첫 유료 결제일을 가입 단계에서 표시하는가
- [ ] 가격 인상·유료 전환 30일 전에 동의 요청을 발송하고, 동의 기록을 남기는가
- [ ] 동의하지 않은 회원의 결제를 자동으로 진행하지 않는가
- [ ] 온라인으로 가입한 회원이 온라인에서 같은 단계 수로 해지할 수 있는가
- [ ] 결제 실패(한도 초과·카드 만료) 시 재시도 횟수와 회원 안내 방식을 결정했는가

## 11. 해외 결제(PayPal 등)를 추가할 때

해외 고객을 대상으로 PayPal 같은 해외 결제를 추가하면 결제수단 하나가 늘어나는 것 이상으로 확인할 항목이 늘어납니다. 결제수단이 해외 결제여도 국내 소비자에게 판매하는 거래라면 1~10절의 표시·환불·거래기록 항목은 똑같이 적용됩니다.

- [ ] 사업자 명의 비즈니스 계정을 개설하고 심사를 통과했는가 (업종에 따라 추가 서류 요구·승인 거절 가능)
- [ ] 판매 통화와 정산 통화를 결정했고, 원화 출금 때 환전 수수료를 확인했는가
- [ ] 결제 시점과 환불 시점의 환율 차이를 누가 부담하는지 환불 규정에 명시했는가
- [ ] 해외 소비자의 분쟁·차지백(카드사 결제 취소 청구)에 대비해 배송 추적번호·서비스 제공 기록을 주문마다 보관하는가
- [ ] 판매 국가별 부가가치세·판매세 처리를 세무 담당자와 확인했는가 (시스템은 입력한 세율로 계산할 뿐 세율을 판단하지 않습니다)
- [ ] 해외 고객에게 보여 줄 환불 규정·약관을 판매 언어로 준비했는가

## 12. 거래기록을 기간별로 보존하고 소비자가 열람하게 한다

사업자는 거래기록을 보존하고 소비자가 쉽게 열람·보존할 수 있는 방법을 제공해야 합니다(제6조 제1항). 위반하면 1천만원 이하 과태료 대상입니다(제45조 제4항 제1호).

| 기록 | 보존 기간 | 근거 |
| --- | --- | --- |
| 표시·광고에 관한 기록 | 6개월 | 시행령 제6조 제1항 제1호 |
| 계약 또는 청약철회 등에 관한 기록 | 5년 | 같은 항 제2호 |
| 대금결제 및 재화등의 공급에 관한 기록 | 5년 | 같은 항 제3호 |
| 소비자의 불만 또는 분쟁처리에 관한 기록 | 3년 | 같은 항 제4호 |

이 기록과 거래 주체를 식별하는 개인정보(성명·주소·전자우편주소 등)는 소비자가 개인정보 이용 동의를 철회해도 보존할 수 있습니다(제6조 제2항). 이때는 동의를 철회하지 않은 소비자의 기록과 분리해 보존해야 합니다(시행령 제6조 제2항 제3호).

- [ ] 주문·결제·취소·환불 내역을 5년 이상 보존하도록 설정했는가
- [ ] 회원 탈퇴 때 거래기록을 일괄 삭제하지 않고 분리 보관으로 옮기는가
- [ ] 소비자가 마이페이지에서 자신의 주문·결제·환불 내역을 확인할 수 있는가 (비회원 주문 조회 포함)
- [ ] 상품 페이지의 가격·조건 변경 이력을 6개월 이상 남기는가

## 14. 연동 전 마지막 확인

- [ ] 사업자 정보·통신판매업 신고번호·이용약관·환불 규정이 사이트에 표시돼 있는가
- [ ] 결제수단별 취소 가능 기간·부분 취소·환불 방식을 확인했는가
- [ ] 결제 직전 주문 요약에 총금액이 표시되고, 동의·추가 상품 항목이 미리 체크돼 있지 않은가
- [ ] 결제 승인 금액을 서버에서 주문 금액과 대조하고, 결제 통보 중복을 처리하는가
- [ ] 반품·청약철회 후 3영업일 안에 PG 취소 또는 환급이 진행되는가
- [ ] 계좌이체·가상계좌 선결제에 에스크로 선택권과 현금영수증 발급이 설정돼 있는가
- [ ] 카드 결제에 추가 금액·불리한 조건이 없고, 다른 사업자 상품을 우리 상점 ID로 결제하지 않는가
- [ ] 정기결제 증액·유료 전환 30일 전 동의 절차와 온라인 해지가 있는가
- [ ] 거래기록을 기간별로 보존하고 소비자가 직접 열람할 수 있는가
