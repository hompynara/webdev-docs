# 골프장 예약 시스템 도입 체크리스트 — 티타임 구조부터 취소 위약금 자동 계산까지

골프장에 실시간 예약을 붙이려고 알아보면 "달력에서 날짜 고르고 시간 고르면 끝"처럼 보입니다. 실제로 갈리는 지점은 화면이 아니라 **같은 티타임이 두 팀에게 팔렸을 때 무엇이 기록에 남는가**, 그리고 **취소가 들어왔을 때 얼마를 받아야 법에 맞는가**입니다. 둘 다 개발 이전에 골프장이 먼저 정해 두셔야 하는 것들입니다.

이 문서는 예약 시스템을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 우리 골프장이 무엇으로 분류되는지부터 확정한다

2023년 1월부터 골프장은 셋으로 나뉩니다. 그 전까지 쓰던 "회원제 / 대중제" 2분류가 아닙니다. **여기가 정해져야 홈페이지에 무엇을 표시하고 요금을 어떻게 운영할지가 정해집니다.**

| 분류 | 요금 운영 | 세제 |
| --- | --- | --- |
| 회원제 | 회원 우선, 입회금·연회비 체계 | 재산세 분리과세 |
| 비회원제 | 제한 없음 | 재산세 종합합산 |
| 대중형 | 정부 고시 기준 이하로 이용료를 유지해야 함 | 재산세 별도합산 등 감면 |

대중형은 세제 혜택을 받는 대신 **그린피를 정부가 고시하는 기준보다 낮게 책정해야 하는** 조건이 붙습니다. 즉 대중형이라면 홈페이지에 올리는 요금표 자체가 지정 조건과 직결됩니다. 요금을 시스템에서 자유롭게 바꿀 수 있게 만들되, **고시 기준을 넘는 값이 실수로 올라가지 않도록** 관리자에 상한 경고를 두는 편이 안전합니다.

- [ ] 우리 골프장이 회원제·비회원제·대중형 중 무엇으로 되어 있는지 확인했는가
- [ ] 대중형이라면 현재 고시 기준과 우리 요금표를 대조해 봤는가
- [ ] 홈페이지에 표시된 분류·요금이 실제 운영과 같은가

## 2. 티타임을 어떤 단위로 파는지 그린다

숙박은 "방 × 날짜"지만 골프장은 "코스 × 날짜 × 시각"입니다. 단위가 하나 늘어나는 만큼 규칙도 늘어납니다.

| 확인 항목 | 왜 물어보는가 |
| --- | --- |
| 코스가 몇 개이고 이름이 무엇인가 | 동·서·남처럼 코스별로 팀이 따로 돕니다 |
| 인터벌이 몇 분인가 (7분·8분 등) | 하루에 생성되는 티타임 개수가 여기서 정해집니다 |
| 1부·2부·3부를 나누는가 | 부별로 요금과 오픈 시각이 다른 경우가 많습니다 |
| 첫 티오프와 마지막 티오프 시각 | 계절별로 다르면 규칙을 계절마다 둬야 합니다 |
| 팀 단위로만 파는가, 조인을 받는가 | 조인을 받으면 1인 단위 재고가 됩니다 |
| 주중·주말·공휴일 요금이 다른가 | 요일 규칙을 달력에 얹어야 합니다 |

- [ ] 코스별 인터벌과 부별 시간대를 표로 만들었는가
- [ ] 계절별로 티오프 시각이 달라지는지 정리했는가
- [ ] 팀 요금인지 1인 요금인지, 카트비·캐디피가 포함인지 별도인지 정했는가

## 3. 누가 언제부터 예약할 수 있는지 정한다

골프장 예약 시스템에서 가장 자주 다시 만들게 되는 부분입니다. 회원제라면 등급이 여럿이고, 등급마다 예약 오픈 시점이 다릅니다.

- [ ] 회원 등급이 몇 개이고 등급별 오픈 시점이 언제인가 (예: 정회원 30일 전, 주중회원 21일 전, 비회원 14일 전)
- [ ] 등급별로 월 예약 가능 횟수 제한이 있는가
- [ ] 주말·공휴일에만 적용되는 별도 규칙이 있는가
- [ ] 오픈 시각에 접속이 몰릴 때 선착순을 무엇으로 판정하는가
- [ ] 동반자 등록을 예약 시점에 받는가, 나중에 받는가

> 오픈 시각에 수백 명이 동시에 들어오는 것이 이 업종의 특징입니다. **"먼저 누른 사람"을 화면에서 판정하면 반드시 분쟁이 생깁니다.** 서버가 접수한 순서로 판정하고, 그 순서가 기록으로 남아야 나중에 설명할 수 있습니다.

## 4. 중복 예약을 막는 방식을 확인한다

같은 티타임이 두 팀에게 팔리면 환불로 끝나지 않습니다. 현장에서 한 팀을 돌려보내야 하고 그 후기가 남습니다.

문제는 대부분 **결제 직전 몇 초** 사이에 생깁니다. 두 사람이 같은 티타임을 동시에 붙잡고 있을 때 먼저 접수된 쪽만 확정되어야 하는데, 화면에서 막는 것으로는 부족합니다. 데이터베이스 단계에서 차단해 뒤에 온 요청이 거부되어야 합니다.

- [ ] 티타임이 점유되는 시점이 예약 신청인가 결제 완료인가
- [ ] 결제 진행 중인 건을 몇 분간 붙잡아 두는가 (미결제 시 자동 해제)
- [ ] 관리자가 수동으로 막아둔 시간(대회·정비·잔디 관리)이 반영되는가
- [ ] 외부 부킹 채널에서 팔린 건이 홈페이지 달력에 즉시 반영되는가 (7번 참고)

## 5. 취소 위약금을 기준대로 자동 계산한다

여기는 임의로 정하면 안 되는 영역입니다. 공정거래위원회 **소비자분쟁해결기준**이 골프장 예약 취소 위약금을 날짜별로 정하고 있고, 2022년 12월 개정으로 산정 기준까지 바뀌었습니다.

| 취소 시점 | 위약금 |
| --- | --- |
| 평일 이용일 3일 전까지 / 주말·공휴일 이용일 4일 전까지 | 없음 |
| 평일 2일 전 / 주말·공휴일 2~3일 전 | 코스 이용요금의 10% |
| 이용일 1일 전 | 20% |
| 이용 당일 | 30% |

주의할 것은 **산정 기준이 입장료 전체가 아니라 카트 이용료 등을 제외한 "골프코스 이용요금"** 이라는 점입니다. 카트비를 포함해 계산하면 기준보다 많이 받게 됩니다. 그리고 **골프장이 예약을 취소하는 경우에도 같은 비율로 이용자에게 배상**하도록 표준약관에 들어가 있습니다.

- [ ] 위약금 계산의 기준 금액에서 카트비를 빼고 있는가
- [ ] 주말·공휴일 판정에 대체공휴일이 포함되는가
- [ ] 골프장 사정으로 취소할 때의 배상 절차가 정해져 있는가
- [ ] 우천·기상 취소를 위약금 없이 처리하는 기준이 약관에 있는가
- [ ] 환불이 결제 수단별로 며칠 안에 이루어지는지 안내하는가

## 6. 노쇼와 인원 변경을 어떻게 다룰지 정한다

취소보다 실제 손실이 큰 쪽은 연락 없이 나타나지 않는 경우입니다.

- [ ] 예약 확인 알림을 며칠 전·몇 시에 보내는가
- [ ] 노쇼 이력을 회원별로 남기고 다음 예약에 제한을 두는가
- [ ] 4인 예약이 3인으로 줄었을 때 요금을 어떻게 처리하는가
- [ ] 취소분이 나오면 대기자에게 자동으로 안내되는가
- [ ] 당일 빈 티타임을 할인해 내보내는 창구가 있는가

## 7. 외부 부킹 채널과의 관계를 정리한다

홈페이지에서만 팔면 이 절은 건너뛰어도 됩니다. 외부 채널을 함께 쓴다면 재고가 두 곳에 존재하게 되므로 어느 쪽이 정본인지부터 정해야 합니다.

- [ ] 어떤 채널에 몇 개의 티타임을 배정하는가
- [ ] 채널에서 팔린 건이 홈페이지에 자동으로 반영되는가, 수동인가
- [ ] 채널별 수수료와 정산 주기를 관리자에서 볼 수 있어야 하는가
- [ ] 채널 예약과 홈페이지 예약의 취소 규정이 다른가

## 8. 회원을 모집한다면 절차가 따로 있다

회원제로 운영하며 회원을 새로 모집한다면 홈페이지에 모집 안내를 올리기 전에 행정 절차가 먼저입니다. 골프장은 등록 체육시설업이므로 **회원모집계획서를 시·도지사에게 제출**해야 하고, 신설 골프장은 **공사 공정률이 30% 이상**이 된 뒤에야 모집할 수 있습니다. 모집 약관에는 **환불 시기와 절차, 이용 조건**이 들어가야 합니다.

- [ ] 회원 모집 계획을 관할 시·도에 제출했는가
- [ ] 홈페이지 모집 안내 문구가 제출한 약관과 같은 내용인가
- [ ] 입회금 반환 시기·절차가 홈페이지에도 표시되어 있는가
- [ ] 회원 등급·정원·연회비를 시스템에서 관리할 것인가

## 9. 개인정보와 알림을 분리해서 본다

- [ ] 예약에 필요한 항목만 받고 있는가 (이름·연락처·동반자 수)
- [ ] 동반자 정보를 받는다면 그 사람의 동의는 어떻게 받는가
- [ ] 예약 정보를 언제까지 보관하고 언제 파기하는가
- [ ] 관리자 계정별로 볼 수 있는 범위가 나뉘어 있는가

> 예약 확인·변경 알림과 **홍보·이벤트 안내는 성격이 다릅니다.** 후자는 정보통신망법 제50조에 따라 사전 수신 동의가 별도로 필요하고, 오후 9시부터 다음 날 오전 8시까지는 야간 발송 동의를 또 받아야 합니다. 예약 알림 동의로 프로모션 문자를 보내면 안 됩니다.

## 10. 도입 전 마지막 확인

- [ ] 회원제·비회원제·대중형 중 우리 분류를 확인하고 요금표를 대조했는가
- [ ] 코스·인터벌·부별 시간표를 표로 만들었는가
- [ ] 등급별 예약 오픈 시점과 횟수 제한을 정했는가
- [ ] 위약금 계산에서 카트비를 제외하도록 설계했는가
- [ ] 노쇼 대응 방식과 대기자 안내 절차를 정했는가
- [ ] 외부 채널을 쓴다면 재고 정본을 어디로 할지 정했는가
- [ ] 관리자를 누가 맡고 예약 확인을 하루 몇 번 할 것인가
