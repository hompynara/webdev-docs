# 그룹웨어 도입 체크리스트 — 기능 요구사항 정리와 비교 기준

그룹웨어를 알아보다 보면 기능 목록이 다 비슷해 보여서 뭘 기준으로 골라야 할지 막막해집니다. 실제로 갈리는 지점은 기능 개수가 아니라 **우리 회사의 결재선과 문서 흐름을 그대로 담을 수 있느냐**입니다.

이 문서는 그룹웨어를 도입하기 전에 발주처가 스스로 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 업무 시스템을 직접 만들어 왔습니다.

## 1. 조직과 권한부터 그린다

기능을 고르기 전에 조직도를 먼저 정리해야 합니다. 여기가 정리 안 되면 어떤 그룹웨어를 써도 결재가 막힙니다.

- [ ] 부서 구조를 몇 단계까지 나눌 것인가
- [ ] 직급과 직책을 구분할 것인가 (팀장 대행, 겸직 처리)
- [ ] 한 사람이 여러 부서에 속하는 경우가 있는가
- [ ] 퇴사자 계정을 어떻게 처리할 것인가 (문서는 남기고 접근만 차단)
- [ ] 외부 협력사에 일부만 열어줄 필요가 있는가

## 2. 결재선 — 여기서 대부분 갈린다

| 확인 항목 | 왜 물어보는가 |
| --- | --- |
| 결재 단계가 문서마다 다른가 | 고정 결재선만 지원하는 제품이 있습니다 |
| 금액에 따라 결재선이 바뀌는가 | 조건부 분기를 지원해야 합니다 |
| 전결 규정이 있는가 | 특정 금액 이하를 팀장 선에서 끝내는 구조 |
| 대결·위임을 쓰는가 | 휴가 중 대리 결재 처리 |
| 병렬 합의가 필요한가 | 여러 부서가 동시에 검토하는 경우 |
| 반려 후 재상신 이력을 남기는가 | 감사 대응에 필요합니다 |

기존에 종이나 엑셀로 돌리던 결재를 그대로 옮기려다 보면 예외 규정이 계속 나옵니다. **도입 전에 실제 결재 문서 10건을 뽑아 흐름을 그려보시길 권합니다.** 이 작업을 미리 해두면 견적 정확도가 크게 올라갑니다.

## 3. 문서와 게시판

- [ ] 어떤 문서 양식을 쓸 것인가 (기안서·품의서·지출결의서 등)
- [ ] 양식을 관리자가 직접 만들 수 있어야 하는가
- [ ] 첨부 파일 용량 한도가 얼마나 필요한가
- [ ] 문서 번호를 자동으로 매길 것인가
- [ ] 부서별로 보이는 게시판을 나눌 것인가
- [ ] 문서를 얼마나 오래 보관할 것인가

## 4. 근태와 일정

회사마다 가장 많이 커스터마이징이 발생하는 영역입니다. 표준 기능으로 되는지 먼저 확인하십시오.

- [ ] 출퇴근 기록을 그룹웨어에서 할 것인가
- [ ] 연차 계산 규칙이 표준인가 (입사일 기준·회계연도 기준)
- [ ] 반차·반반차를 쓰는가
- [ ] 부서 일정을 공유할 것인가
- [ ] 회의실·차량 예약이 필요한가

## 5. 알림과 접근

- [ ] 결재 요청을 어떤 경로로 알릴 것인가 (메일·문자·알림톡·앱 푸시)
- [ ] 모바일에서 결재할 수 있어야 하는가
- [ ] 사내에서만 접속할 것인가, 외부에서도 열 것인가
- [ ] 외부 접속을 허용한다면 인증을 어떻게 할 것인가

## 6. 데이터 이관

기존에 쓰던 것이 있다면 이관 범위를 먼저 정해야 합니다. 이 항목을 빼놓고 견적을 받으면 나중에 비용이 늘어납니다.

- [ ] 직원 정보를 옮길 것인가
- [ ] 과거 결재 문서를 옮길 것인가, 조회용으로만 남길 것인가
- [ ] 게시판 글과 첨부 파일을 옮길 것인가
- [ ] 옮길 데이터가 엑셀로 정리 가능한 형태인가

## 7. 구축 방식 비교

| 기준 | 확인할 것 |
| --- | --- |
| 비용 구조 | 사용자당 월 과금인지, 구축 후 소유인지 |
| 인원 변동 | 직원이 늘면 비용이 어떻게 되는지 |
| 데이터 위치 | 우리 서버인지 업체 서버인지, 해지 시 데이터를 받을 수 있는지 |
| 커스터마이징 | 우리 결재 규정에 맞게 고칠 수 있는지, 비용은 얼마인지 |
| 연동 | 기존 홈페이지·회계 프로그램과 연결할 수 있는지 |

사용자당 월 과금 방식은 처음엔 저렴해 보이지만 인원이 늘수록 부담이 커집니다. 반대로 구축형은 초기 비용이 들지만 인원 증가에 따른 추가 비용이 없습니다. **3년 기준 총비용으로 비교**하시길 권합니다.

## 8. 도입 전 마지막 확인

- [ ] 실제 결재 문서 10건의 흐름을 그려봤는가
- [ ] 예외 규정을 목록으로 뽑았는가
- [ ] 이관 범위를 정했는가
- [ ] 관리자를 누가 맡을 것인가
- [ ] 직원 교육 일정을 잡았는가
