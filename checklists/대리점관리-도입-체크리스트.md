# 대리점 관리·발주 시스템 도입 체크리스트 — 대리점법 적용 여부부터 주문 기록·반품·판매장려금 정산까지

카카오톡과 엑셀로 주고받던 대리점 발주를 시스템으로 옮기면 주문이 한곳에 모이고, 출고와 정산이 같은 기록에서 이어집니다. 도입 뒤의 결과를 좌우하는 것은 기능 목록보다 따로 있습니다. **대리점이 넣은 주문을 누가 어떻게 고칠 수 있고 그 기록이 남는가**, **시스템에 설정한 단가·판매장려금·반품 조건이 계약서와 같은가**, 그리고 **본사가 대리점에게서 어떤 정보까지 가져오는가**입니다. 셋 다 대리점거래의 공정화에 관한 법률(이하 대리점법)과 직접 연결되므로, 시스템을 고르기 전에 회사 쪽에서 먼저 결정해 두셔야 합니다.

이 문서는 대리점 관리·발주 시스템을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 우리 거래가 대리점법 대상인지 먼저 확인한다

대리점법의 「대리점거래」는 공급업자와 대리점 사이에 상품이나 용역을 **재판매하거나 위탁판매하기 위해**, 일정 기간 지속되는 계약을 맺고 반복적으로 하는 거래입니다(제2조 제1호). 다만 아래에 해당하면 대리점법이 적용되지 않습니다.

| 구분 | 대리점법 적용 여부 | 근거 |
| --- | --- | --- |
| 공급업자(본사)가 중소기업자 | 적용하지 않음 | 제3조 제1항 제1호 (중소기업기본법 제2조) |
| 대리점이 중소기업자가 아님 | 적용하지 않음 | 제3조 제1항 제2호 |
| 본사가 대리점에 거래상 우월한 지위가 없음 | 적용하지 않음 (시장 구조·사업능력 격차·거래 의존도·상품 특성으로 판단) | 제3조 제1항 제3호 |
| 가맹사업에 해당하는 거래 | 대리점법이 아니라 가맹사업법 적용 | 제3조 제2항 제1호 |

가맹사업은 본사가 가맹점에 **자기 상표·상호·간판 같은 영업표지**를 쓰게 하고 일정한 품질기준이나 영업방식에 따라 팔게 하면서 지원·교육·통제를 하고, 가맹점은 그 대가로 **가맹금**을 내는 계속적인 거래입니다(가맹사업법 제2조 제1호). 같은 시스템에 대리점과 가맹점이 함께 들어온다면 거래처마다 어느 법이 적용되는지 구분해 두셔야 계약서 양식과 공개 의무가 섞이지 않습니다.

대리점법이 적용되지 않는 거래라도, 자기의 거래상 지위를 부당하게 이용해 상대방과 거래하는 행위는 공정거래법의 불공정거래행위로 금지됩니다(독점규제 및 공정거래에 관한 법률 제45조 제1항 제6호). 아래 항목은 적용 여부와 관계없이 분쟁을 줄이는 설계 기준입니다.

- [ ] 우리 회사(공급업자)가 중소기업기본법상 중소기업자인지 확인했는가
- [ ] 거래 중인 대리점 가운데 중소기업자가 아닌 곳이 있는지 확인했는가
- [ ] 영업표지를 쓰고 가맹금을 내는 가맹점이 섞여 있다면 거래처를 대리점·가맹점으로 나눴는가
- [ ] 재판매(대리점이 사서 되팖)와 위탁판매(수수료를 대가로 대신 판매) 거래를 구분했는가

## 2. 대리점거래 계약서를 전자로 제공하고 3년 보관한다

본사는 대리점과 계약을 체결한 **즉시** 아래 사항이 명시된 계약서를 서면으로 제공해야 합니다. 서면에는 전자문서가 포함되고, 서명은 실지명의를 확인할 수 있는 전자서명도 인정됩니다(제5조 제1항·제2항).

| 기재사항 | 근거 |
| --- | --- |
| 거래형태, 거래품목과 기간 | 제5조 제1항 제1호 |
| 납품방법, 납품장소와 일시 | 제2호 |
| 상품대금의 지급수단과 지급시기 | 제3호 |
| 상품의 반품조건 | 제4호 |
| 영업의 양도 | 제5호 |
| 계약해지의 사유와 계약해지 절차 | 제6호 |
| 판매장려금 지급 | 제7호 |
| (위탁판매) 위탁하는 업무의 범위와 수행방법, 수수료 등 대리점에 지급하는 대가 | 제8호, 시행령 제2조 |

계약서는 대리점거래가 **종료된 날부터 3년간** 보관해야 합니다(제5조 제3항). 계약서를 제공하지 않거나 서명·기명날인이 빠지면 5천만원 이하, 보관하지 않으면 1천만원 이하의 과태료 대상입니다(제32조 제1항 제4호·제5호). 공정거래위원회는 업종별 **표준대리점계약서**를 마련해 사용을 권장하고 있습니다(제5조의2).

- [ ] 대리점 계약서를 시스템에서 전자로 제공하고 양쪽 서명 기록을 남기는가
- [ ] 위 기재사항이 계약서 양식에 모두 들어 있는가 (위탁판매라면 수수료 항목 포함)
- [ ] 거래가 끝난 대리점의 계약서를 종료일부터 3년 이상 보관하도록 설정했는가
- [ ] 우리 업종의 표준대리점계약서가 있는지 확인했는가

> 계약서의 반품조건·판매장려금·대금 지급시기는 시스템의 반품 처리·장려금 계산·정산 일정과 같은 내용이어야 합니다. **계약서와 시스템 설정이 따로 관리되면** 분쟁이 생겼을 때 어느 쪽이 기준인지부터 다투게 됩니다.

## 3. 대리점이 넣은 주문의 원본과 변경 이력을 남긴다

발주 시스템에서 가장 먼저 결정할 것은 **주문을 누가 고칠 수 있는가**입니다. 대리점법은 두 가지를 금지합니다.

| 금지 행위 | 근거 | 벌칙 |
| --- | --- | --- |
| 대리점이 청약하거나 구입의사를 표시한 제품·수량 등 **주문내역의 정당한 확인요청을 거부·회피** | 제11조 | 2년 이하 징역 또는 1억5천만원 이하 벌금 (제30조 제1항 제6호) |
| **대리점의 주문내용을 일방적으로 수정**해 구입할 의사가 없는 상품·용역을 공급 | 제6조, 시행령 제3조 제2호 (구입강제) | 같은 벌칙 (제30조 제1항 제1호) |

카카오톡이나 전화로 들어온 주문은 나중에 「그때 몇 개를 주문했는지」 확인이 필요할 때 원본을 찾기 어렵습니다. 대리점이 직접 입력한 주문을 원본 그대로 두고, 본사의 수정은 별도 기록으로 쌓는 구조가 기본입니다.

- [ ] 대리점이 입력한 주문 원본이 수정·삭제되지 않고 그대로 보관되는가
- [ ] 본사가 수량이나 품목을 바꿀 때 대리점 확인을 거친 뒤에 확정되는가
- [ ] 누가 언제 무엇을 바꿨는지 변경 이력이 주문마다 남는가
- [ ] 대리점이 자기 주문·변경·출고 내역을 언제든 직접 조회할 수 있는가
- [ ] 전화·카카오톡으로 들어온 주문도 시스템에 등록해 같은 기록으로 관리하는가
- [ ] 재고 부족으로 일부만 출고할 때 대리점에 사유와 수량이 표시되는가

## 4. 권장 수량·판매목표 기능은 대리점이 결정하는 구조로 만든다

시스템이 과거 판매량으로 권장 발주 수량을 계산해 주는 기능은 편리합니다. 다만 권장 수량이 **대리점 확인 없이 주문으로 바로 넘어가면** 주문 일방 수정과 같은 결과가 됩니다. 대리점이 특정 상품을 주문하도록 강요하거나 **주문할 수밖에 없는 상황을 조성하는 것**도 구입강제입니다(시행령 제3조 제1호).

판매목표를 제시하는 것 자체보다, 목표 미달을 이유로 **계약을 중도에 해지하거나 공급을 중단하거나 지급할 금액을 주지 않는 것**(또는 그렇게 하겠다고 표시하는 것)이 판매목표 강제입니다(제8조, 시행령 제5조).

- [ ] 권장 발주 수량은 제안으로만 표시되고 대리점이 확정해야 주문이 되는가
- [ ] 신제품·재고 소진 상품을 대리점 주문에 자동으로 끼워 넣는 설정이 없는가
- [ ] 판매목표 달성률을 공급 중단·출고 보류·장려금 미지급과 자동으로 연결하지 않았는가
- [ ] 목표 관련 안내 문구가 불이익을 암시하지 않는지 확인했는가

## 5. 판매장려금과 공급단가는 계약서 조건대로 계산한다

판매장려금은 명칭과 관계없이 상품 판매촉진을 위해 본사가 대리점에 지급하는 경제적 이익입니다(제2조 제5호). 계약서의 판매장려금 **지급 제한 사유에 해당하지 않는데 삭감하거나 지급하지 않는 것**, 그리고 계약 기간 중에 **대리점의 의사에 반해 거래조건을 추가하거나 변경하는 것**은 불이익 제공행위입니다(제9조, 시행령 제6조 제2호·제5호).

본사가 판촉행사를 하면서 그 비용이나 인력을 대리점이 부담하도록 강요하는 것은 경제상 이익 제공 강요로 따로 금지됩니다(제7조, 시행령 제4조 제1호).

- [ ] 대리점별 공급단가와 장려금 조건이 계약서 버전과 연결돼 있는가
- [ ] 장려금 삭감·미지급은 계약서의 제한 사유를 선택해야만 처리되는가
- [ ] 단가·조건을 바꿀 때 적용 시작일과 대리점 합의 기록이 함께 남는가
- [ ] 대리점이 정산 내역(주문·출고·반품·장려금)을 항목별로 확인할 수 있는가
- [ ] 판촉행사 비용을 대리점에 배분하는 기능이 있다면 대리점 동의 절차가 있는가

## 6. 반품은 귀책 사유를 나눠 처리한다

반품은 형식과 관계없이 공급받은 상품을 본사에 실질적으로 되돌려주는 모든 행위입니다(제2조 제4호). 본사의 귀책으로 상품이 파손되거나 훼손됐는데 **반품을 거부하는 것**, 본사 귀책 반품인데 **운송비 등 반품 비용을 대리점에 부담하게 하는 것**은 불이익 제공행위입니다(시행령 제6조 제7호·제8호).

- [ ] 반품 신청 때 사유(파손·오배송·유통기한·단순 변심 등)를 고르게 되어 있는가
- [ ] 사유별로 귀책(본사·운송·대리점)이 구분되고 그에 맞춰 반품 비용 부담자가 결정되는가
- [ ] 파손 사진과 입고 검수 결과를 반품 건에 첨부할 수 있는가
- [ ] 반품 처리 결과와 정산 반영 여부를 대리점이 조회할 수 있는가

## 7. 대리점에게서 가져오는 정보를 필요한 범위로 제한한다

시스템을 연결하면 대리점의 판매처·매출 데이터까지 본사로 모을 수 있게 됩니다. 다만 합리적인 이유 없이 대리점에 **거래처 현황, 매출 내역 등 영업상 비밀에 해당하는 정보를 제공하도록 요구하는 것**, 대리점의 **거래처·영업시간·영업지역·판촉활동을 본사가 일방적으로 지정해 이행을 요구하는 것**은 경영활동 간섭입니다(제10조, 시행령 제7조 제2호·제3호).

- [ ] 대리점의 판매처·고객·매출 정보를 가져오는 기능이 있다면 그 목적과 범위를 계약에 두었는가
- [ ] 그런 정보는 대리점이 선택해서 공유하는 구조인가
- [ ] 본사 재고 현황처럼 대리점에 보여 주는 정보와, 대리점에게서 가져오는 정보를 구분해 설계했는가
- [ ] 영업시간·판촉 일정 같은 항목을 시스템에서 강제 입력하게 만들지 않았는가

## 8. 공급 중단·물량 조정에는 사유를 남긴다

대리점이 분쟁조정을 신청하거나 공정거래위원회에 신고·조사 협조·서면실태조사 협조를 했다는 이유로 **거래를 정지하거나 물량을 줄이는 것**은 보복조치로 금지됩니다(제12조). 합리적인 이유 없이 상품 공급이나 약정한 영업지원을 중단·제한하는 것도 불이익 제공행위입니다(시행령 제6조 제4호).

손해배상은 본사가 고의·과실이 없음을 입증하지 못하면 부담하고, 구입강제(제6조)·경제상 이익 제공 강요(제7조)·보복조치(제12조)는 **손해의 3배**까지 배상책임을 집니다(제34조).

- [ ] 대리점별 출고 정지·공급 제한을 걸 때 사유를 반드시 입력하게 되어 있는가
- [ ] 여신 한도 초과처럼 계약서에 근거한 사유를 선택지로 둘 수 있는가
- [ ] 공급 제한 이력과 해제 시점이 대리점별로 남는가

## 10. 도입 전 마지막 확인

- [ ] 거래처별로 대리점법·가맹사업법 적용 여부를 구분했는가
- [ ] 계약서를 즉시 전자로 제공하고 종료일부터 3년 보관하는가
- [ ] 대리점 주문 원본이 남고, 본사 수정은 대리점 확인을 거치는가
- [ ] 대리점이 자기 주문·변경·출고·정산 내역을 직접 조회할 수 있는가
- [ ] 권장 수량과 판매목표가 강제 주문·불이익과 자동으로 연결되지 않는가
- [ ] 장려금·단가·반품 비용이 계약서 조건대로 계산되는가
- [ ] 대리점에게서 가져오는 정보의 목적과 범위를 계약에 두었는가
- [ ] 공급 중단·물량 조정에 사유가 기록되는가
