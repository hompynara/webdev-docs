# 부동산 매물관리 시스템·중개사무소 홈페이지 도입 체크리스트 — 매물 등록 항목부터 광고 명시사항·거래완료 처리까지

부동산 매물 홈페이지를 알아보면 지도 검색과 필터가 먼저 보입니다. 실제로 운영을 좌우하는 것은 둘입니다. **매물 하나를 올릴 때 법이 요구하는 항목이 빠짐없이 들어가는가**, 그리고 **계약된 매물을 언제 어떻게 내리는가**입니다. 홈페이지에 올린 매물은 공인중개사법이 말하는 중개대상물 표시·광고이고, 두 가지 모두 과태료 기준이 정해져 있습니다.

이 문서는 매물관리 시스템을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 모든 매물에 사무소 정보를 명시한다

중개대상물을 표시·광고할 때는 매체와 상관없이 아래 사항을 밝혀야 합니다(공인중개사법 제18조의2 제1항, 시행령 제17조의2 제1항). 명시사항을 빠뜨리면 **100만원 이하 과태료**(부과기준 50만원) 대상입니다(법 제51조 제3항).

| 구분 | 명시할 사항 |
| --- | --- |
| 중개사무소 | 명칭 · 소재지 · 연락처 · 등록번호 |
| 개업공인중개사 | 성명 (법인은 대표자 성명) |

연락처에는 **등록관청에 신고한 번호**만 표시할 수 있습니다. 중개보조원에 관한 사항은 표시·광고에 명시하면 안 되므로 중개보조원의 이름이나 휴대폰 번호를 매물에 올릴 수 없습니다. 소속공인중개사는 「소속공인중개사」라고 밝히면 번호를 함께 표시할 수 있습니다(국토교통부 고시 「중개대상물의 표시·광고 명시사항 세부기준」 제3조).

- [ ] 사무소 명칭·소재지·연락처·등록번호·대표자 성명이 매물 상세 페이지마다 보이게 되어 있는가
- [ ] 사무소 정보를 한 번 입력하면 모든 매물에 자동으로 표시되는 구조인가
- [ ] 매물 담당자 칸에 중개보조원의 이름·번호가 들어가지 않게 막았는가
- [ ] 소속공인중개사 번호를 표시한다면 「소속공인중개사」 표기가 함께 나오는가

> 매물마다 사무소 정보를 손으로 입력하면 한 건만 빠져도 명시사항 위반입니다. **사무소 정보는 설정에 한 번 넣고 매물 상세 페이지 틀이 자동으로 표시하게** 만드는 것이 가장 확실합니다.

## 2. 매물 등록 양식을 인터넷 광고 명시사항에 맞춘다

인터넷으로 표시·광고할 때는 1번 항목에 더해 매물 정보를 명시해야 합니다(법 제18조의2 제2항, 시행령 제17조의2 제2항). 매물 등록 양식의 필수 항목이 곧 이 목록입니다.

| 대상 | 추가로 명시할 사항 |
| --- | --- |
| 모든 중개대상물 | 소재지 · 면적 · 가격 · 중개대상물 종류 · 거래 형태 |
| 건축물 | 위 항목 + 총 층수 · 사용승인일(사용검사일·준공검사일) · 방향 · 방 수 · 욕실 수 · 입주 가능일 · 주차 대수 · 관리비 |

표시 방법은 국토교통부 고시(제2024-748호, 2025.1.1 시행)가 정합니다. 양식 설계에 바로 반영해야 하는 규칙은 이렇습니다.

| 항목 | 표시 방법 |
| --- | --- |
| 면적 | 전용면적을 제곱미터(㎡)로 표시 |
| 가격 | 단일 가격으로 표시 (매매가, 임대차는 보증금·차임) |
| 거래 형태 | 임대차는 전세·월세를 구분 |
| 소재지(공동주택 등) | 지번·동·층수까지 표시. 의뢰인이 원하면 층은 저·중·고로 표시 |
| 건축물 상태 | 미등기 건물·위반 건축물은 그 사실을 표시 |
| 방향 | 8방위로 표시하고 방향을 잰 기준을 함께 표시 |
| 관리비 | 정액 관리비가 월 10만원 이상이면 고시가 정한 항목별로 나눠 표시 |
| 토지 | 소재지·면적·가격·종류(지목)·거래 형태 |

- [ ] 매물 종류(아파트·오피스텔·상가·토지 등)에 따라 필수 항목이 바뀌는 양식인가
- [ ] 필수 항목을 비워 두면 등록이 되지 않게 막았는가
- [ ] 평으로 입력하더라도 공개 페이지에는 전용면적 ㎡가 표시되는가
- [ ] 가격 칸이 「협의」나 「3억~3억5천」 같은 범위를 받지 않고 단일 금액만 받는가
- [ ] 층수를 저·중·고로 바꿔 표시하는 선택지가 있는가
- [ ] 방향 입력에 기준(거실·안방 등)을 함께 고르게 되어 있는가
- [ ] 관리비가 월 10만원 이상일 때 항목별 금액을 입력하는 칸이 열리는가

> 명시사항은 사람이 기억해서 채우면 반드시 빠지는 항목이 생깁니다. **필수 항목을 양식이 강제하게** 만들면 담당자가 바뀌어도 누락이 없습니다. 평 단위로 상담하는 현장이라면 입력은 평으로 받고 표시는 ㎡로 바꿔 주는 쪽이 입력 부담이 적습니다.

## 3. 부당한 표시·광고 유형을 등록 단계에서 거른다

공인중개사법은 다섯 가지 표시·광고를 금지합니다(법 제18조의2 제4항, 시행령 제17조의2 제4항). 과태료 상한은 **500만원**이고 유형마다 부과 기준액이 다릅니다(법 제51조 제2항, 시행령 별표 2).

| 금지 유형 | 부과 기준액 |
| --- | --- |
| 존재하지 않아 실제로 거래할 수 없는 매물 | 500만원 |
| 존재하지만 실제로 중개할 수 없는 매물 | 400만원 |
| 가격 등 내용을 사실과 다르게 거짓으로 표시하거나 부풀린 것 | 300만원 |
| 입지 조건·생활 여건·가격·거래 조건 등 중요한 사실을 빠뜨리거나 숨긴 것 | 300만원 |
| 존재하지만 중개할 의사가 없는 매물 | 250만원 |

기준액은 위반 정도에 따라 2분의 1 범위에서 줄이거나 늘릴 수 있지만 500만원을 넘을 수는 없습니다. 국토교통부 고시 「부당한 중개대상물 표시·광고행위의 유형 및 기준」은 전단·인터넷 같은 매체를 가리지 않고 적용되며, 다음과 같은 경우를 예로 듭니다.

- 의뢰받지 않은 매물을 임의로 광고하는 것
- 의뢰받은 가격과 다른 가격으로 광고하는 것
- 그 매물이 아닌 다른 매물의 사진을 사용하는 것
- 실제 방향과 90도 이상 차이 나는 방향을 표시하는 것

- [ ] 매물 등록 때 의뢰인과 의뢰 일자를 함께 기록하는가
- [ ] 의뢰받은 가격이 바뀌면 누가 언제 광고 가격을 고치는지 정했는가
- [ ] 사진을 매물별로 올리게 되어 있고, 다른 매물 사진을 재사용하지 않는가
- [ ] 압류·가처분처럼 거래에 영향을 주는 사실을 입력할 칸이 있는가

## 4. 계약된 매물을 내리는 절차를 정한다 (2026.7.3 고시 개정)

거래완료 매물 처리 기준은 **2026년 7월 3일 시행된 고시 개정(제2026-345호)으로 바뀌었습니다.** 개정 전에는 계약 사실을 알고도 광고를 지체 없이 삭제하지 않으면 부당한 표시·광고였습니다. 이 유형이 삭제되고, 지금은 아래 두 경우가 부당한 표시·광고에 해당합니다(고시 제5조 제2항).

| 부당한 표시·광고가 되는 경우 | 내용 |
| --- | --- |
| 계약된 매물을 미끼로 사용 | 계약된 사실을 알면서 광고를 두고, 그 매물을 보고 문의한 사람에게 다른 매물을 권하는 것 |
| 통보 후 3일 경과 | 국토교통부·시·도·등록관청에서 계약 체결 사실을 통보받은 날부터 3일 안에 광고를 삭제하지 않는 것 |

2023년 국토교통부 가이드라인을 비롯한 개정 전 자료는 「지체 없이 삭제」 기준으로 설명하고 있으니 자료의 날짜를 확인하셔야 합니다. 한국부동산원은 2022년 1월부터 거래완료 광고의 삭제 여부를 모니터링하고 있습니다.

부동산 거래신고는 계약 체결일부터 **30일 이내**입니다. 중개사가 거래계약서를 작성·교부했다면 신고도 중개사가 합니다(「부동산 거래신고 등에 관한 법률」 제3조). 주택 임대차 신고와 계약 해제 신고도 각각 30일 이내입니다.

- [ ] 관리자 페이지에서 매물을 거래완료로 바꾸면 공개 목록에서 바로 내려가는가
- [ ] 완료 매물을 실적으로 남긴다면 문의 버튼이 막히고 「거래완료」가 분명히 보이는가
- [ ] 관청의 계약 체결 통보를 누가 받고, 받은 날부터 3일 안에 누가 삭제하는지 정했는가
- [ ] 같은 매물을 부동산 플랫폼에도 올렸다면 홈페이지와 플랫폼을 함께 내리는 절차가 있는가
- [ ] 거래완료로 바꾼 날짜가 매물 기록에 남는가

> 완료 매물을 목록에 남겨 두고 문의가 오면 다른 매물을 권하는 흐름이 바로 첫 번째 유형입니다. **완료 처리와 동시에 문의 경로가 닫히도록** 만들어 두면 운영자가 의도하지 않아도 그런 흐름이 생기지 않습니다.

## 5. 블로그·SNS 광고도 같은 기준으로 관리한다

국토교통부 가이드라인(2023.9.21)은 유튜브·블로그·인스타그램·틱톡에 올리는 매물 광고에도 명시사항이 적용된다고 안내합니다. 개업공인중개사가 아닌 사람이 중개업을 하기 위해 표시·광고하면 **1년 이하 징역 또는 1천만원 이하 벌금** 대상입니다(법 제18조의2 제3항, 제49조 제1항).

국토교통부는 인터넷 표시·광고를 모니터링하고, 정보통신서비스 제공자에게 자료 제출과 확인·추가 정보 게재 같은 조치를 요구할 수 있습니다(법 제18조의3). 정당한 사유 없이 따르지 않으면 500만원 이하 과태료입니다.

- [ ] 홈페이지 매물을 블로그·SNS에 옮겨 올릴 때 명시사항이 함께 옮겨지는가
- [ ] 거래완료 처리할 때 블로그·SNS에 올린 게시물 목록도 함께 확인하는가
- [ ] 중개보조원이 자기 SNS에 매물을 올리지 않도록 내부 기준을 정했는가

## 6. 계약서와 확인·설명서 보관 기능을 정한다

매물관리 시스템에 계약 서류를 함께 보관한다면 보존 기간을 기준으로 삭제 규칙을 만들어야 합니다.

| 서류 | 보존 기간 | 근거 |
| --- | --- | --- |
| 중개대상물 확인·설명서 | 3년 | 법 제25조 제3항, 시행령 제21조 제4항 |
| 거래계약서 | 5년 | 법 제26조 제1항, 시행령 제22조 제2항 |

거래계약서는 원본·사본·전자문서 중 하나로 보존하면 됩니다. **공인전자문서센터에 보관된 경우에는 보존 의무가 없고**, 부동산거래 전자계약시스템으로 작성한 계약서는 공인전자문서센터에 5년간 보관되므로 따로 출력해 둘 필요가 없다고 국토교통부가 안내합니다. 보존 의무를 어기면 업무정지 사유가 됩니다(법 제39조).

- [ ] 계약 서류를 시스템에 올린다면 서류 종류별로 보존 기간이 따로 적용되는가
- [ ] 전자계약시스템으로 계약한 건과 종이 계약 건을 구분해서 관리하는가
- [ ] 보존 기간이 지난 서류를 누가 언제 삭제하는지 정했는가
- [ ] 계약 서류 파일을 볼 수 있는 관리자 계정을 제한했는가

## 7. 등록증·중개보수표 게시는 사무소 안이 기준이다

중개사무소 등록증, 중개보수·실비의 요율과 한도액표, 자격증, 보증설정 증명서류, 사업자등록증은 **중개사무소 안의 보기 쉬운 곳**에 게시해야 합니다(법 제17조, 시행규칙 제10조). 홈페이지에 게시하라는 조문은 없습니다. 홈페이지에 반드시 들어가야 하는 것은 1번의 명시사항입니다.

- [ ] 사무소 안에 게시할 서류가 빠짐없이 게시되어 있는가 (게시하지 않으면 100만원 이하 과태료)
- [ ] 홈페이지에 중개보수 안내를 둔다면 현행 요율표와 같은지 확인했는가

## 8. 의뢰인 개인정보와 업무상 비밀을 관리한다

매물관리 시스템에만 적용되는 공인중개사법 규정은 없습니다. 매도인·임대인·매수 희망자의 이름과 연락처를 저장하면 개인정보 보호법이 그대로 적용되고, 안전성 확보조치(제29조)를 갖춰야 합니다. 주민등록번호는 법령에 근거가 있을 때만 처리할 수 있으므로(제24조의2) 매물 의뢰와 문의를 받는 단계의 입력 항목에는 넣지 않습니다.

개업공인중개사와 소속공인중개사, 중개보조원은 업무상 알게 된 비밀을 누설하면 안 되고, 이 의무는 **업무를 떠난 뒤에도** 계속됩니다(공인중개사법 제29조 제2항). 위반하면 1년 이하 징역 또는 1천만원 이하 벌금 대상입니다.

- [ ] 매물 공개 페이지와 의뢰인 정보(이름·연락처·메모)가 분리되어 공개 페이지에 노출되지 않는가
- [ ] 직원 계정마다 볼 수 있는 의뢰인 정보 범위가 나뉘어 있는가
- [ ] 퇴사한 직원의 계정을 바로 막는 절차가 있는가
- [ ] 의뢰인 정보를 엑셀로 내려받을 수 있는 권한을 제한했는가
- [ ] 문의 폼에서 받는 항목과 보관 기간이 개인정보처리방침에 공개되어 있는가

> 지도에 매물 위치를 표시할 때는 정확한 좌표가 그대로 공개되는 것도 생각해야 합니다. 의뢰인이 층수를 저·중·고로 표시해 달라고 한 매물이라면 **지도 핀과 상세 주소로 층이나 호수가 드러나지 않는지** 함께 확인해야 합니다.

## 9. 도입 전 마지막 확인

- [ ] 사무소 명시사항이 모든 매물에 자동으로 표시되는가
- [ ] 매물 종류별 필수 항목을 양식이 강제하는가
- [ ] 면적 ㎡·단일 가격·전세/월세 구분이 표시 규칙에 맞는가
- [ ] 중개보조원 정보가 매물에 표시되지 않는가
- [ ] 거래완료 처리와 동시에 공개 목록과 문의 경로가 닫히는가
- [ ] 관청 통보 후 3일 안에 삭제하는 담당자가 정해져 있는가
- [ ] 계약 서류의 보존 기간(확인·설명서 3년 · 거래계약서 5년)을 반영했는가
- [ ] 의뢰인 정보를 볼 수 있는 계정과 내려받기 권한을 제한했는가
