# 상담 위젯 도입 체크리스트 — 채널 통합부터 상담 기록 파기·AI 챗봇 고지까지

홈페이지에 상담 위젯을 설치하려고 알아보면 "버튼 하나 추가하면 끝"처럼 보입니다. 실제로 결과를 좌우하는 것은 셋입니다. **문의가 들어왔을 때 누가 몇 분 안에 답하는가**, **채팅으로 받은 이름·연락처를 어디에 얼마나 보관하는가**, 그리고 챗봇이 생성형 AI라면 **이용자에게 AI라는 사실을 알리는 의무**를 어떻게 이행하는가입니다. 셋 다 위젯 제품을 고르기 전에 운영하는 쪽에서 먼저 정해 두셔야 합니다.

이 문서는 상담 위젯을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 어떤 채널을 위젯 하나에 모을지 정한다

위젯은 채널을 모으는 창구일 뿐이고, 답변은 채널마다 다른 곳에서 합니다. 채널을 고르는 순간 대화 기록이 남는 곳과 답변하는 사람의 작업 방식이 정해집니다.

| 채널 | 방문자 쪽 | 운영자 쪽에서 달라지는 것 |
| --- | --- | --- |
| 카카오톡 채널 | 카카오톡 앱으로 넘어가 대화 | 카카오톡 채널 관리자에서 답변 · 대화 기록이 카카오 쪽에 남습니다 |
| 네이버 톡톡 | 네이버 계정으로 대화 | 네이버 톡톡 파트너센터에서 답변 |
| 전화 연결 | 모바일에서 바로 발신 | 통화 내용이 시스템에 남지 않고 부재중 처리가 따로 필요합니다 |
| 사이트 내 채팅 | 페이지를 벗어나지 않고 대화 | 상담원용 관리 페이지가 필요하고 기록이 우리 서버나 솔루션사 서버에 저장됩니다 |
| 문의 폼 | 내용을 남기고 나감 | 답변이 메일·문자로 나중에 가서 응답 기대 시간이 가장 깁니다 |

- [ ] 기존 문의가 실제로 어느 경로로 가장 많이 들어오는지 확인했는가
- [ ] 위젯에 노출할 채널을 몇 개로 정할 것인가
- [ ] 채널마다 대화 기록이 어디에 저장되는지 알고 있는가
- [ ] 여러 채널의 문의를 한곳에서 보는 기능이 필요한가

> 채널을 늘리는 것보다 **들어온 문의를 놓치지 않는 것**이 먼저입니다. 카카오톡·전화·채팅 문의가 서로 다른 사람에게 가면 같은 고객에게 두 번 답하거나 아무도 답하지 않는 일이 생깁니다.

## 2. 누가 언제 답하는지부터 정한다

- [ ] 상담 운영 요일과 시간대를 정했는가
- [ ] 운영 시간 밖에 들어온 문의를 어떻게 받는가 (부재 안내와 연락처 남기기)
- [ ] 운영 시간 중 첫 응답 목표 시간을 정했는가
- [ ] 담당자가 자리를 비웠을 때 누구에게 넘어가는가
- [ ] 새 문의 알림을 어디로 받는가 (관리자 앱 푸시·문자·메일)
- [ ] 알림 받는 사람이 휴가·퇴사일 때 수신자를 바꾸는 절차가 있는가

> 채팅 창을 열었는데 답이 오지 않으면 문의 폼보다 결과가 나쁩니다. 방문자는 기다리다 페이지를 닫습니다. **실시간으로 답할 인원이 없다면 "남겨 주시면 연락드립니다" 방식으로 운영하는 것이 맞습니다.**

## 3. 위젯이 어느 페이지에서 언제 뜰지 정한다

- [ ] 모든 페이지에 띄우는가, 가격·상품 상세·예약 페이지에만 띄우는가
- [ ] 자동으로 말을 거는 메시지를 사용할 것인가, 조건(체류 시간·스크롤·방문 페이지)은 무엇인가
- [ ] 결제·주문서·문의 폼 페이지에서는 위젯을 숨길 것인가
- [ ] 모바일에서 위젯 버튼이 하단의 전화·구매·예약 버튼을 가리지 않는가
- [ ] 한 번 닫은 방문자에게 자동 메시지를 반복해서 띄우지 않는가

> 들어오자마자 뜨는 자동 메시지는 본문 읽기를 방해합니다. **가격표를 일정 시간 이상 본 방문자**처럼 조건을 좁혀 두면 필요한 사람에게만 보입니다.

## 4. 페이지 속도와 본문 가림을 확인한다

외부 채팅 솔루션은 보통 스크립트 한 줄을 넣는 방식입니다. 그 한 줄이 불러오는 파일의 크기는 제품마다 다르고, 캐릭터 영상이 들어간 위젯은 영상 파일 하나가 1MB를 넘기도 합니다. 모바일 검색으로 들어온 방문자에게는 이 무게가 그대로 대기 시간이 됩니다.

- [ ] 위젯 스크립트가 본문을 다 불러온 뒤에 실행되도록 되어 있는가
- [ ] 위젯이 불러오는 파일(스크립트·이미지·영상)의 전체 크기를 확인했는가
- [ ] 설치 전과 후에 모바일 페이지 속도를 같은 도구로 측정해 비교했는가
- [ ] 위젯이 나타나면서 본문이 밀려 움직이지 않는가

## 5. 자동 응답과 챗봇이 어디까지 답할지 정한다

- [ ] 자주 받는 질문(영업시간·위치·가격·배송·예약 변경)을 목록으로 뽑아 두었는가
- [ ] 자동 응답이 정해진 답을 고르는 방식인가, 생성형 AI가 문장을 만드는 방식인가
- [ ] 자동 응답이 답하지 못할 때 상담원에게 넘기는 조건이 있는가
- [ ] 가격·환불·계약 조건처럼 틀리면 분쟁이 되는 질문은 챗봇이 답하지 않게 정했는가
- [ ] 챗봇 답변 기록을 누가 얼마 주기로 검토하는가

> **생성형 AI 챗봇은 사실과 다른 답을 자연스러운 문장으로 만들 수 있습니다.** 챗봇이 가격이나 환불 기준을 잘못 안내하면 그 안내를 근거로 항의가 들어옵니다. 이런 질문은 정해진 답변이나 상담원 연결로 처리하도록 범위를 정해 두셔야 합니다.

## 6. 생성형 AI 챗봇이라면 AI라는 사실을 알린다

2026년 1월 22일 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」(인공지능 기본법)이 시행됐습니다. **의무 대상은 고영향 AI와 생성형 AI입니다.** 버튼을 눌러 정해진 답을 고르는 시나리오형 챗봇은 이 조항의 대상이 아닙니다.

| 조문 | 내용 |
| --- | --- |
| 법 제31조 제1항 | 고영향·생성형 AI를 이용한 제품·서비스를 제공할 때 AI에 기반해 운용된다는 사실을 이용자에게 미리 고지 |
| 법 제31조 제2항 | 생성형 AI로 만든 결과물이라는 사실을 표시 |
| 시행령 제23조 | 고지 방법(약관 기재·이용자가 보는 창에 표시·제공 장소 게시 등) · 서비스 명칭이나 안내 문구로 AI 활용이 명백한 경우의 적용 예외 |
| 법 제43조 제1항 제1호 | 제31조 제1항 고지 의무 위반 시 3천만원 이하 과태료 |

의무를 지는 사업자에는 다른 회사가 만든 AI를 이용해 서비스를 제공하는 **인공지능이용사업자**도 포함됩니다(법 제2조). 방문자와 직접 대화하는 챗봇을 홈페이지에 설치하면 여기에 해당할 수 있습니다. 과학기술정보통신부는 시행 시점에 1년 이상의 계도기간을 두고 그 기간 동안 사실조사와 과태료 부과를 유예한다고 발표했고, 대화형 서비스는 이용 전 안내나 대화창 안의 표시(로고)로 고지를 인정한다고 밝혔습니다.

- [ ] 우리 챗봇이 생성형 AI인지, 정해진 답을 고르는 방식인지 확인했는가
- [ ] 생성형이라면 대화를 시작하기 전에 AI라는 안내가 보이는가 (첫 메시지·대화창 상단 문구·로고)
- [ ] 외부 AI 솔루션을 사용한다면 그 안내를 솔루션이 기본으로 표시하는지, 우리가 넣어야 하는지 확인했는가
- [ ] 상담원에게 연결된 뒤에는 사람이 답한다는 것이 구분되는가

> 계도기간은 조사와 과태료 부과를 미루는 정부 방침이고 의무 자체를 없앤 것이 아닙니다. **위젯을 새로 설치하는 시점에 안내 문구를 함께 넣는 것이 비용이 가장 적습니다.**

## 7. 채팅으로 받는 개인정보의 수집 근거를 정한다

채팅 상담에서 이름과 연락처를 받는다고 해서 항상 동의가 필요한 것은 아닙니다. 개인정보 보호법 제15조 제1항 제4호는 **계약 체결 과정에서 정보주체의 요청에 따른 조치**에 필요한 경우 동의 없이 수집할 수 있게 합니다. 대신 개인정보보호위원회의 「개인정보 처리 통합 안내서」(2025.7.)는 계약이 체결되지 않은 경우 수집한 개인정보를 즉시 파기해야 한다고 안내합니다.

동의를 받아 처리한다면 목적·항목·보유기간·거부할 권리와 거부 시 불이익 네 가지를 알리고(제15조 제2항), 동의 사항을 구분해서 받아야 합니다(제22조). 홍보·판매 권유에 쓰려면 그 목적의 동의를 따로 받아야 합니다.

- [ ] 채팅에서 받는 항목을 필요한 만큼으로 정했는가 (이름·연락처·문의 내용)
- [ ] 항목마다 수집 근거가 상담 요청 응대인지, 별도 동의인지 정했는가
- [ ] 상담이 계약으로 이어지지 않았을 때 언제 파기하는가
- [ ] 이벤트·홍보 안내에 사용하려면 그 동의를 따로 받는가
- [ ] 동의 없이 처리하는 항목과 근거를 개인정보처리방침에 공개했는가 (제22조 제3항)
- [ ] 만 14세 미만이 이용할 수 있는 서비스라면 법정대리인 동의 절차가 있는가 (제22조의2)

> **채팅창은 자유 입력이라 받을 생각이 없던 정보까지 들어옵니다.** 건강에 관한 정보는 민감정보라 다른 동의와 별도로 동의를 받아야 하고(제23조), 계약 체결 과정이라는 근거로는 처리할 수 없습니다. 병원·한의원·심리상담처럼 증상을 말하기 쉬운 업종은 "진료와 관련된 자세한 내용은 방문 상담에서 확인합니다" 같은 안내를 대화창 안에 두는 것이 현실적인 방법입니다.

## 8. 외부 채팅 솔루션을 사용하면 위탁 사실을 공개한다

대화 기록이 솔루션 회사 서버에 저장되면 개인정보 처리를 위탁한 것입니다(제26조). 위탁 계약은 문서로 남겨야 하고, 위탁하는 업무 내용과 수탁자를 **우리 홈페이지에 계속 게재**해야 합니다(시행령 제28조). 두 가지 모두 어기면 각각 1천만원 이하 과태료 대상입니다.

솔루션 서버가 해외에 있으면 국외 이전에도 해당합니다(제28조의8). 계약 이행에 필요한 처리위탁·보관이라면 별도 동의 없이 가능하지만, 이전하는 항목·국가와 시기·방법·받는 자·이용 목적과 보유기간·거부 방법을 개인정보처리방침에 공개해야 합니다.

- [ ] 대화 기록이 저장되는 곳이 우리 서버인지, 솔루션 회사 서버인지 확인했는가
- [ ] 솔루션 회사와의 위탁 계약(이용약관·데이터 처리 부속 문서)을 보관하고 있는가
- [ ] 개인정보처리방침의 위탁 항목에 솔루션 회사 이름과 맡긴 업무를 추가했는가
- [ ] 서버가 해외에 있다면 국외 이전 사항 다섯 가지를 처리방침에 공개했는가
- [ ] 솔루션을 해지할 때 쌓인 대화 기록을 내려받고 삭제할 수 있는가

## 9. 상담 기록의 보관 기간과 파기 방법을 정한다

보유기간이 지나거나 처리 목적을 달성한 개인정보는 지체 없이 파기해야 하고, 다른 법령 때문에 보존해야 하면 분리해서 보관해야 합니다(제21조). 파기하지 않으면 3천만원 이하 과태료 대상입니다.

온라인으로 상품이나 서비스를 판매하는 사업자라면 전자상거래법 제6조와 시행령 제6조가 거래 기록의 보존 기간을 정합니다.

| 기록 | 보존 기간 |
| --- | --- |
| 표시·광고에 관한 기록 | 6개월 |
| 계약 또는 청약철회 등에 관한 기록 | 5년 |
| 대금결제 및 재화 등의 공급에 관한 기록 | 5년 |
| 소비자의 불만 또는 분쟁처리에 관한 기록 | 3년 |

상담 채팅 기록 전체가 「불만 또는 분쟁처리에 관한 기록」에 해당한다는 공식 해석은 확인되지 않습니다. 그래서 **일반 상담과 불만·분쟁 상담을 구분해 두고 보관 기간을 따로 적용하는 방식**이 두 법의 요구를 함께 맞추기 쉽습니다.

- [ ] 일반 상담 기록의 보관 기간을 정했는가
- [ ] 기간이 지난 기록이 자동으로 삭제되는가, 누가 삭제하는가
- [ ] 온라인 판매 사업자라면 불만·분쟁 상담을 따로 표시할 수 있는가
- [ ] 관리자 계정마다 상담 기록을 볼 수 있는 범위가 나뉘어 있는가
- [ ] 퇴사한 상담원의 계정을 바로 막는 절차가 있는가

## 10. 상담 뒤에 보내는 홍보 메시지는 수신 동의를 따로 받는다

영리 목적의 광고성 정보를 보내려면 받는 사람의 명시적인 사전 동의가 필요합니다(정보통신망법 제50조 제1항). 거래가 끝난 날부터 6개월 안에 같은 종류의 상품을 안내하는 경우에는 예외가 있지만, 방송미디어통신위원회·한국인터넷진흥원 안내서(2025.12.)는 **단순 문의는 거래관계의 성립으로 볼 수 없다**고 명시합니다. 상담만 하고 계약하지 않은 사람에게 보내는 이벤트 문자에는 이 예외가 적용되지 않습니다.

| 조문 | 내용 |
| --- | --- |
| 제50조 제1항 | 광고성 정보 전송 전 명시적 사전 동의 |
| 제50조 제3항 | 오후 9시부터 다음 날 오전 8시까지 전송은 별도 동의 (전자우편은 제외) |
| 제50조 제7항 | 수신 동의·거부·철회 의사를 받은 날부터 14일 이내 처리 결과 통지 |
| 제50조 제8항 | 수신 동의를 받은 날부터 2년마다 동의 여부 확인 |
| 제76조 제1항 | 동의 없는 전송 등 3천만원 이하 과태료 |

- [ ] 상담 답변 메시지와 홍보 메시지를 구분하고 있는가
- [ ] 홍보 메시지 수신 동의를 상담 개인정보 동의와 따로 받는가
- [ ] 동의서에 전송 매체(문자·카카오톡·메일)를 구체적으로 표시했는가
- [ ] 오후 9시 이후에 홍보 메시지를 보낼 일이 있다면 야간 동의를 따로 받는가
- [ ] 동의받은 날부터 2년마다 확인 안내가 나가는가
- [ ] 수신 거부가 바로 반영되고 14일 안에 처리 결과를 알리는가

## 11. 키보드와 스크린리더로도 사용할 수 있는지 확인한다

장애인차별금지법 제21조와 시행령 별표 3에 따라 **법인은 2013년 4월 11일부터 웹사이트 접근성 보장 의무 대상**입니다. 개인사업자는 원칙적으로 이 조항의 대상에서 빠지고, 의료기관처럼 따로 열거된 경우에는 별도 기준이 적용됩니다. 상담 위젯도 웹사이트에서 제공하는 서비스의 일부입니다. 키보드 조작·대체 텍스트 같은 세부 기준은 국가표준인 한국형 웹 콘텐츠 접근성 지침에서 확인하시기 바랍니다.

- [ ] 키보드 Tab 키만으로 위젯을 열고, 입력하고, 닫을 수 있는가
- [ ] 위젯 버튼에 "상담 창 열기" 같은 이름이 있어 스크린리더가 읽을 수 있는가
- [ ] 자동으로 뜨는 메시지가 본문을 읽는 도중 초점을 빼앗지 않는가
- [ ] 위젯 글자와 배경의 명도 대비가 충분한가

## 12. 도입 전 마지막 확인

- [ ] 모을 채널과 채널별 대화 기록 저장 위치를 정했는가
- [ ] 운영 시간·첫 응답 목표·부재 시 처리 방식을 정했는가
- [ ] 위젯을 띄울 페이지와 자동 메시지 조건을 정했는가
- [ ] 설치 전후 모바일 페이지 속도를 비교했는가
- [ ] 챗봇이 답하지 않을 질문(가격·환불·계약)을 정했는가
- [ ] 생성형 AI 챗봇이라면 대화 시작 전 안내 문구를 넣었는가
- [ ] 개인정보처리방침에 위탁 솔루션·국외 이전·보관 기간을 반영했는가
- [ ] 홍보 메시지 수신 동의를 상담과 따로 받는가
