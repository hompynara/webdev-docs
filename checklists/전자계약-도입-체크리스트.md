# 전자계약 도입 체크리스트 — 계약 종류별 확인 항목과 시스템 요건

전자계약을 도입하기로 정했다면, 솔루션을 고르기 전에 우리 회사가 다루는 계약이 전자문서로 처리 가능한지부터 확인해야 합니다. 이 문서는 발주처가 제작사나 솔루션 업체와 이야기하기 전에 스스로 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다.

작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 우리 계약이 전자문서로 되는지부터

전자문서는 전자적 형태라는 이유만으로 법적 효력이 부인되지 않습니다(전자문서 및 전자거래 기본법 제4조 제1항). 다만 **법이 서면을 요구하는 경우**에는 별도 요건을 갖춰야 서면으로 인정됩니다.

| 확인 항목 | 판단 기준 |
| --- | --- |
| 계약 종류를 목록으로 뽑았는가 | 근로·용역·매매·임대차·동의서 등 실제 쓰는 것 전부 |
| 각 계약에 서면 요구 규정이 있는가 | 소관 법령에 서면 교부·작성 의무가 따로 있는지 |
| 성질상 전자적 형태가 안 되는 것이 섞였는가 | 제4조의2 단서에 해당하는지 |
| 상대방이 전자서명에 동의할 수 있는가 | 계약 조건이나 약관에 근거를 넣을 수 있는지 |

근로계약서처럼 개별 법령이 서면 교부를 정한 문서가 있습니다. 전자문서로 가능한 경우에도 요건이 따로 붙을 수 있으니 소관 법령을 먼저 확인하십시오.

## 2. 서면으로 인정받기 위한 두 요건

전자문서법 제4조의2는 다음 두 가지를 모두 갖춘 전자문서를 서면으로 봅니다.

1. 전자문서의 내용을 **열람할 수 있을 것**
2. 작성·변환되거나 송신·수신 또는 저장된 때의 형태 또는 **그와 같이 재현될 수 있는 형태로 보존**되어 있을 것

솔루션을 검토할 때 이 두 가지가 실제로 되는지 물어보십시오. 계약서를 나중에 열어볼 수 있는지, 서명 당시 화면 그대로 다시 볼 수 있는지가 핵심입니다.

## 3. 서명 방식 확인

전자서명은 전자적 형태라는 이유만으로 효력이 부인되지 않고, 당사자가 약정으로 선택했다면 서명·기명날인의 효력을 가집니다(전자서명법 제3조).

2020년 6월 9일 개정으로 공인인증서 제도가 폐지됐습니다. 현행 전자서명법 제6조 제2항은 법령에서 수단을 특정한 경우를 제외하고 **특정한 전자서명수단만 쓰도록 제한해서는 안 된다**고 정합니다. 특정 인증서를 반드시 써야 한다는 설명을 듣는다면 근거 법령이 무엇인지 확인하십시오.

- [ ] 서명 방식(마우스·터치·인증서 연동) 중 무엇을 쓸지 정했는가
- [ ] 본인 확인 절차를 어디까지 할지 정했는가(휴대폰 인증, 사설 인증 등)
- [ ] 상대방이 앱 설치 없이 서명할 수 있는가
- [ ] 서명 거부·중단 시 처리 방식을 정했는가

## 4. 보관과 이력

전자문서법 제5조 제1항은 전자문서 보관으로 관계 법령이 정하는 문서 보관을 갈음할 수 있다고 정합니다. 조건은 제4조의2에 따라 서면으로 보는 전자문서일 것, 그리고 작성자·수신자·송수신 일시가 포함돼 있다면 그 부분이 보존돼 있을 것입니다.

종이 계약서를 스캔해 보관하려면 같은 조 제2항이 적용됩니다. 위 요건에 더해 **원본과 내용 및 형태가 동일**해야 합니다.

- [ ] 보관 기간을 계약 종류별로 정했는가 (근거 법령이 각각 다릅니다)
- [ ] 백업과 복구 방식을 정했는가
- [ ] 누가 언제 열람했는지 기록이 남는가
- [ ] 서명 후 문서가 바뀌지 않았음을 확인할 수단이 있는가

문서 변조 확인은 보통 해시값 비교로 합니다. 여기서 오해하기 쉬운 점이 있는데, 해시는 변조를 **탐지**하는 수단이지 수정 자체를 막는 수단이 아닙니다. "1바이트도 수정할 수 없다"는 설명을 들으면 실제로는 "수정되면 반드시 드러난다"는 뜻인지 확인하십시오.

## 5. 운영 준비

- [ ] 계약 양식을 템플릿으로 등록해 둘 것인지
- [ ] 상대방에게 어떤 경로로 보낼 것인지(문자·알림톡·메일)
- [ ] 진행 상태(열람·서명 대기·완료)를 누가 확인할 것인지
- [ ] 담당자 권한을 어떻게 나눌 것인지
- [ ] 기존 회원·거래처 데이터와 연결할 것인지

## 6. 솔루션 비교 기준

구독형 서비스를 쓸지, 자사 홈페이지에 기능을 넣을지는 계약 건수와 운영 방식에 따라 갈립니다.

| 기준 | 확인할 것 |
| --- | --- |
| 비용 구조 | 월 구독료인지 구축 후 소유인지, 건당 과금이 있는지 |
| 데이터 위치 | 계약서가 어느 서버에 남는지, 해지하면 어떻게 되는지 |
| 흐름 | 상대방이 외부 사이트로 이동하는지, 자사 사이트에서 끝나는지 |
| 확장 | 기존 회원·주문 데이터와 연결할 수 있는지 |
| 이관 | 나중에 다른 방식으로 옮길 때 데이터를 받을 수 있는지 |
