# 포인트 적립 프로그램 도입 체크리스트 — 적립·사용 규칙부터 취소 회수·소멸 안내·제휴 포인트·충전금까지

포인트 적립은 쇼핑몰이나 매장에서 가장 먼저 도입하는 재방문 장치입니다. 결제 금액의 몇 %를 적립해 주는 기능은 어느 솔루션에나 있어서, 도입 자체는 어렵지 않습니다. 운영을 시작한 뒤 문제가 되는 지점은 따로 있습니다. **주문을 취소하거나 일부만 반품할 때 적립한 포인트와 사용한 포인트를 어떻게 되돌리는가**, **포인트 소멸 안내가 광고 문자가 되는 경계가 어디인가**, 그리고 **포인트를 다른 회사 쿠폰으로 바꿔 주거나 돈을 미리 받아 충전해 주는 순간 적용되는 법이 달라진다는 점**입니다. 셋 다 프로그램을 만들기 전에 회사 쪽에서 규칙으로 결정해 두셔야 합니다.

이 문서는 포인트 적립 프로그램을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 어떤 금액에 몇 %를 적립할지 결정한다

적립률보다 먼저 결정할 것은 **적립 기준 금액**입니다. 같은 5% 적립이라도 기준이 상품 가격인지, 쿠폰·포인트를 뺀 실제 결제 금액인지에 따라 지급되는 포인트가 달라집니다.

| 결정할 것 | 보통 고르는 방식 | 함께 확인할 것 |
| --- | --- | --- |
| 적립 기준 금액 | 쿠폰 할인과 포인트 사용분을 뺀 실제 결제 금액 | 배송비를 기준 금액에 넣는지 |
| 적립 시점 | 결제 즉시가 아니라 구매 확정(또는 배송 완료 후 일정 기간) 시점 | 구매 확정 전에는 「적립 예정」으로 따로 보여 줄지 |
| 등급별 적립률 | 등급마다 다른 비율 | 등급을 매기는 기준 기간(최근 3개월·6개월 등)과 갱신 날짜 |
| 이벤트 적립 | 회원가입·리뷰 작성·생일 지급 | 구매 적립과 유효기간을 다르게 할지 (6절의 광고 판단과도 연결) |
| 오프라인 매장 적립 | 전화번호로 회원 조회 후 적립 | 매장 직원 계정별로 누가 적립했는지 기록되는지 |

- [ ] 적립 기준 금액(배송비·쿠폰·포인트 사용분 포함 여부)을 결정했는가
- [ ] 적립 시점을 결제 즉시로 할지, 구매 확정 후로 할지 결정했는가
- [ ] 등급별 적립률과 등급 산정 기간·갱신일을 결정했는가
- [ ] 구매 적립과 이벤트 적립(가입·리뷰·생일)을 원장에서 구분해 기록하는가
- [ ] 적립률을 바꾸면 바꾼 날 이후 주문에만 적용되는가

> 결제 즉시 적립하면 고객 만족도는 높지만, 적립되자마자 포인트를 사용한 뒤 주문을 취소하는 경우가 생깁니다. **구매 확정 후 적립으로 두면 4절의 회수 문제가 대부분 사라집니다.**

## 2. 포인트 사용 규칙을 결정한다

- [ ] 최소 보유 포인트(예: 1,000포인트 이상부터 사용)를 결정했는가
- [ ] 한 주문에서 결제 금액의 최대 몇 %까지 포인트로 결제할 수 있는지 결정했는가
- [ ] 포인트 사용이 안 되는 상품(할인 상품·정기 구독 등)이 있는지 결정했는가
- [ ] 포인트와 쿠폰을 한 주문에 같이 사용할 수 있는지 결정했는가
- [ ] 포인트 1점의 가치(예: 1포인트 = 1원)를 이용약관에 명시했는가

## 3. 포인트 원장(변동 이력)을 기록한다

포인트를 회원 정보에 「잔액」 숫자 하나로만 저장하면 나중에 설명할 수 없는 차이가 생깁니다. 적립·사용·회수·소멸·관리자 조정을 **건마다 한 줄씩 기록하고, 잔액은 그 기록의 합계로 계산하는 구조**(원장)로 만들어야 고객 문의와 8절의 세무·회계 처리에 대응할 수 있습니다.

- [ ] 포인트 변동이 건마다(일시·사유·관련 주문번호·처리자) 기록되는가
- [ ] 회원의 현재 잔액과 변동 기록의 합계가 항상 일치하는가
- [ ] 관리자가 포인트를 수동으로 지급·차감하면 사유 입력이 필수인가
- [ ] 적립 건마다 유효기간이 따로 저장되어 먼저 소멸할 포인트부터 사용되는가
- [ ] 고객이 마이페이지에서 적립·사용·소멸 내역을 날짜별로 확인할 수 있는가
- [ ] 전체 회원의 미사용 포인트 합계를 날짜 기준으로 조회할 수 있는가

## 4. 취소·반품 때 포인트를 되돌리는 규칙을 결정한다

통신판매로 판 상품의 청약철회가 들어오면 재화를 반환받은 날부터 **3영업일 이내**에 대금을 환급해야 하고, 신용카드 결제분은 결제업자에게 청구 취소를 요청해야 합니다(전자상거래법 제18조 제2항·제3항). 포인트로 결제한 부분을 어떻게 돌려줄지는 법과 시행령에 문구가 없어, **이용약관에 미리 정해 둔 규칙**이 기준이 됩니다.

다만 현금으로 결제한 금액을 포인트로만 돌려주는 방식은 허용되지 않습니다. 공정거래위원회는 2023년 「마일리지로만 환불 가능」이라고 고지한 쇼핑몰을 청약철회 방해(제21조 제1항 제1호)로 보고 과태료와 영업정지를 부과했습니다.

| 상황 | 결정할 것 |
| --- | --- |
| 포인트로 일부 결제한 주문을 전체 취소 | 사용한 포인트를 그대로 돌려줄지, 돌려줄 때 원래 유효기간을 유지할지 |
| 일부 상품만 반품 | 사용 포인트를 상품 금액 비율로 나눠 돌려줄지, 현금 결제분부터 환불할지 |
| 적립까지 끝난 주문을 반품 | 지급한 적립 포인트를 회수할지, 이미 사용해 잔액이 부족하면 어떻게 할지 |
| 돌려준 포인트의 유효기간이 이미 지남 | 바로 소멸시킬지, 일정 기간 연장해 줄지 |

- [ ] 전체 취소와 부분 반품 때 사용 포인트를 돌려주는 계산 방식을 결정했는가
- [ ] 현금·카드 결제분은 원래 결제수단으로 환급되고 포인트로 대신 지급되지 않는가
- [ ] 적립 포인트 회수 시 잔액이 부족하면 마이너스 잔액을 허용할지, 환불 금액에서 차감할지 결정했는가
- [ ] 위 규칙을 이용약관과 주문 페이지에 공개했는가
- [ ] 취소·반품을 처리하면 포인트 회수·복원이 자동으로 원장에 기록되는가

## 5. 유효기간과 소멸 규칙을 약관에 명시한다

구매에 따라 무상으로 지급하는 적립 포인트의 유효기간을 몇 년 이상으로 하라고 정한 법 조항은 확인되지 않습니다. 신용카드 포인트를 다루는 여신전문금융업법과 감독규정에도 「6개월 전 소멸 고지」 같은 조항은 없습니다. 유효기간은 사업자가 이용약관으로 정하되, 약관의 규제에 관한 법률의 기준을 함께 보셔야 합니다.

| 사례 | 내용 |
| --- | --- |
| 공정위 2011.11.23 (이동통신사) | 바뀐 약관으로 이미 적립된 포인트를 소급해 소멸시킨 것을 원상회복. 「변경된 약관은 향후에만 적용될 수 있을 뿐 소급적용은 불가」 |
| 공정위 2015.2.6 (카드사 7곳) | 탈회했다는 이유만으로 남은 포인트를 소멸시키는 조항 시정 |
| 공정위 2026.4.27 (오픈마켓 7곳) | 탈퇴 시 돈을 내고 충전한 캐시는 소멸시킬 수 없고 환급해야 함. 무상으로 지급한 분만 소멸 가능 |
| 공정위 2024.12.23 실태조사 | 유효기간 5년, 소멸 고지 3회(2개월 전·1개월 전·3일 전)를 자율개선으로 권고. 시정명령은 아님 |

근거 조문은 약관법 제6조(신의성실), 제9조(계약 해제·해지 시 원상회복), 제10조 제1호(상당한 이유 없이 급부 내용을 일방적으로 변경하는 조항)입니다.

- [ ] 구매 포인트와 이벤트 포인트의 유효기간을 각각 결정해 약관에 명시했는가
- [ ] 유효기간이나 적립률을 바꿀 때 이미 적립된 포인트에는 기존 기준이 유지되는가
- [ ] 유효기간이 지나면 자동으로 소멸 처리되고 원장에 「소멸」로 기록되는가
- [ ] 소멸 예정 안내 시점(예: 1개월 전)과 횟수를 결정했는가
- [ ] 회원 탈퇴 시 남은 포인트 처리 방법을 약관에 명시했는가 (유상 충전분이 있으면 환급)

## 6. 포인트 안내 문자와 광고 문자를 구분한다

영리 목적의 광고성 정보를 보내려면 받는 사람의 명시적인 사전 동의가 필요하고, 오후 9시부터 다음 날 오전 8시까지는 별도 동의가 필요합니다(정보통신망법 제50조 제1항·제3항). 2026년 10월 2일 시행된 개정으로 위반 시 관련 매출액의 100분의 6 이하 과징금 조항(제50조의9)이 신설됐습니다.

포인트 문자가 광고인지는 **어떤 포인트의 안내인가**로 판단합니다. 방송미디어통신위원회·한국인터넷진흥원 「불법스팸 방지를 위한 정보통신망법 안내서」 제7차(2025.12.)의 기준은 다음과 같습니다.

| 문자 내용 | 안내서 판단 |
| --- | --- |
| 구매로 적립된 포인트의 소멸 예정 안내 | 안내성 정보 — 광고성 정보에 해당하지 않음 |
| 가입·생일처럼 일방적으로 지급한 쿠폰·마일리지의 발급·소멸 안내 | 광고성 정보 |
| 구매 적립금 소멸 안내에 생일 적립금을 함께 안내 | 안내성 정보 |
| 일방 지급분만 따로 안내 | 광고성 정보 |
| 남은 쿠폰·마일리지를 주기적으로 상기시키는 문자 | 광고성 정보에 해당할 수 있음 |

이 기준대로라면 1절에서 구매 적립과 이벤트 적립을 원장에서 구분해 두어야 문자를 보낼 때 대상을 나눌 수 있습니다.

- [ ] 구매 적립 소멸 안내와 이벤트 포인트 안내를 발송 대상에서 구분하는가
- [ ] 이벤트 포인트 안내는 광고 수신 동의 고객에게만, (광고) 표기와 수신거부 방법을 넣어 발송하는가
- [ ] 소멸 안내 문자에 할인 상품 추천 같은 구매 권유 문구가 섞이지 않게 관리하는가
- [ ] 오후 9시 이후 예약 발송을 야간 동의 고객에게만 허용하는가
- [ ] 「포인트 잔액 안내」를 매월 정기 발송한다면 광고로 보고 동의 고객에게만 발송하는가

## 7. 다른 회사 쿠폰으로 바꿔 주거나 돈을 받아 충전하면 적용되는 법이 달라진다

전자금융거래법의 선불전자지급수단은 「이전 가능한 금전적 가치가 전자적 방법으로 저장되어 발행된 증표」로서 **발행인 외의 제3자로부터 재화 또는 용역을 구입하고 그 대가를 지급하는 데 사용되는 것**입니다(제2조 제14호). 예전에는 「2개 업종 이상」에서 사용될 것이 요건이었지만 이 요건은 2023년 9월 14일 개정으로 삭제됐고 2024년 9월 15일부터 시행 중입니다.

| 운영 방식 | 금융위원회 해석·법 조항 |
| --- | --- |
| 우리 매장·쇼핑몰에서만 사용하는 포인트 | 「마트 1개에서만 사용되는 선불전자지급수단을 발행하는 경우 특별한 사정이 없는 한 선불업 등록 면제대상」 (금융위원회 법령해석 회신 2025.3.21) |
| 포인트를 제휴사 쿠폰으로 교환해 주는 경우 | 제3자인 제휴사의 재화·용역 구입에 사용되면 선불전자지급수단. 면제 요건이 아니면 등록 대상 (같은 날 회신) |
| 등록 면제 요건 | 하나의 가맹점(사업주가 같은 경우)에서만 사용 · 발행잔액 30억원 미만이고 연간 총발행액 500억원 미만 · 이용자가 미리 직접 대가를 지불하지 않은 수단으로서 상환보증보험 등에 가입 (제28조 제3항 제1호, 시행령 제15조 제5항·제6항) |
| 등록한 선불업자의 의무 | 선불충전금 100%를 신탁·예치·지급보증보험으로 별도 관리(제25조의2, 시행령 제13조의2) · 미리 약정한 바에 따른 잔액 환급(제19조) |

2026년 12월 17일 시행 예정인 개정 전자금융거래법에서도 위 정의와 면제 조항은 바뀌지 않습니다.

돈을 받고 충전금이나 모바일 상품권을 판매하면 공정거래위원회 「소비자분쟁해결기준」(고시 제2025-14호)의 신유형 상품권 기준이 적용됩니다. 구매 후 7일 이내에는 전액 환급하고, 유효기간이 지났더라도 상사채권 소멸시효(5년) 안이면 5만원 이하는 90%, 5만원 초과는 95%를 돌려줍니다. 이 기준은 돈을 받고 판 상품권에 관한 것이고, 구매에 따라 무상으로 지급한 적립 포인트에 대한 규정은 아닙니다.

- [ ] 포인트를 우리 매장·쇼핑몰 밖에서 사용하게 할 계획이 있는지 확인했는가
- [ ] 제휴사 쿠폰·상품권으로 교환해 주는 기능이 있으면 선불업 등록 면제 요건을 확인했는가
- [ ] 돈을 받고 충전해 주는 기능(예치금·충전 캐시)을 넣을지 결정했는가
- [ ] 충전 기능을 넣는다면 7일 이내 환급과 유효기간 경과 후 환급 기준을 약관에 반영했는가
- [ ] 충전 캐시와 무상 적립 포인트를 원장에서 따로 관리하는가 (탈퇴·소멸 처리가 다르다)

## 8. 부가가치세와 회계 처리를 확인한다

부가가치세법 시행령 제61조는 「별도의 대가 없이 적립받은 후 다른 재화 또는 용역 구입 시 결제수단으로 사용할 수 있는 것」을 마일리지등으로 정의합니다. 우리 회사가 직접 적립해 준 포인트로 결제한 금액은 공급가액에 포함되지 않습니다. 제휴 포인트처럼 다른 회사가 적립해 준 포인트로 결제하고 그 회사로부터 대금을 보전받으면, **보전받았거나 받을 금액이 공급가액에 더해집니다**(같은 조 제2항 제9호). 보전을 받지 않거나 특수관계인이 부당하게 낮게 보전하면 시가로 계산합니다(제10호).

회계에서는 한국채택국제회계기준 제1115호가 판매 때 지급한 포인트를 별도의 수행의무로 봅니다. 판매 대금 일부를 포인트 몫으로 배분해 두었다가, 포인트가 사용되거나 소멸할 때 수익으로 인식합니다(문단 B40·B42, 적용사례 IE267~268). 일반기업회계기준을 적용하는 회사의 처리와 법인세법상 비용 귀속 시기는 세무사와 확인하십시오.

- [ ] 주문별로 자사 포인트 결제액과 제휴 포인트 결제액이 따로 기록되는가
- [ ] 제휴 포인트는 제휴사에서 보전받은 금액을 주문별로 대조할 수 있는가
- [ ] 월말 기준 미사용 포인트 합계와 월별 적립·사용·소멸액을 조회할 수 있는가
- [ ] 매출 자료에 포인트 결제분이 현금·카드 결제분과 구분되어 표시되는가
- [ ] 위 자료로 세무사와 부가가치세·회계 처리 방식을 확인했는가

## 9. 기존 포인트를 옮겨 온다

이미 다른 솔루션이나 엑셀로 포인트를 관리하고 있다면, 새 프로그램으로 옮길 때 잔액 숫자만 옮기지 말고 유효기간이 남은 적립 건 단위로 옮겨야 소멸 일정이 유지됩니다.

- [ ] 기존 시스템에서 회원별 잔액과 적립 건별 유효기간을 내려받을 수 있는지 확인했는가
- [ ] 적립 건 단위로 내려받을 수 없으면 이관 잔액에 적용할 유효기간을 결정했는가 (기존보다 짧아지지 않게)
- [ ] 이관 전날 기준 잔액 합계와 이관 후 잔액 합계가 일치하는지 대조하는가
- [ ] 구매 적립·이벤트 적립·충전 캐시를 구분해 옮기는가
- [ ] 이관 날짜와 바뀌는 점을 회원에게 미리 공지하는가

## 10. 도입 전 마지막 확인

- [ ] 적립 기준 금액·적립 시점·등급별 적립률을 결정했는가
- [ ] 포인트 변동이 건마다 원장에 기록되고 잔액과 일치하는가
- [ ] 취소·부분 반품 때 포인트를 되돌리는 계산을 약관에 공개했고, 현금 결제분은 현금으로 환급하는가
- [ ] 유효기간을 바꿔도 이미 적립된 포인트에는 기존 기준이 유지되는가
- [ ] 구매 적립 소멸 안내와 이벤트 포인트 안내를 구분해 발송하는가
- [ ] 포인트를 다른 회사 쿠폰으로 교환해 주거나 충전 캐시를 판매하는지 확인했는가
- [ ] 미사용 포인트 합계를 날짜 기준으로 뽑아 세무사와 처리 방식을 확인했는가
