# 학원관리 프로그램 도입 체크리스트 — 반 편성·수납부터 환불 계산·알림 발송까지

학원관리 프로그램을 알아보면 기능 목록이 다 비슷해 보입니다. 출결, 수납, 문자, 성적. 실제로 갈리는 지점은 둘입니다. **중도에 그만둔 학생에게 얼마를 돌려주는가**와 **밤 9시가 넘어 보내는 알림이 안내인가 광고인가**입니다. 앞엣것은 학원이 정하는 게 아니라 법이 정해 두었고, 뒤엣것은 학원 수업이 대개 9시 넘어 끝나기 때문에 거의 모든 학원이 매일 마주칩니다.

이 문서는 프로그램을 맡기기 전에 정리해 두면 견적과 일정이 정확해지는 항목을 모았습니다. 작성한 곳은 [홈피나라](https://hompynara.kr) — 2003년부터 비즈니스 웹사이트와 예약·관리 프로그램을 직접 만들어 왔습니다.

## 1. 무엇을 관리 단위로 삼는지 먼저 정한다

여기서 데이터 구조가 갈립니다. 학원마다 "반"이라는 말의 뜻이 다릅니다.

| 관리 단위 | 어떤 학원에 맞나 | 시스템에서 생기는 일 |
| --- | --- | --- |
| 반 단위 | 정해진 요일·시간에 같은 학생이 오는 학원 | 학생은 반에 소속된다. 출결은 반 단위로 찍는다 |
| 강좌 단위 | 학생마다 듣는 과목이 다른 종합반 | 학생 하나가 여러 강좌를 가진다. 수납도 강좌별로 갈린다 |
| 개인 시간표 | 1:1·소수정예, 시간을 개별 조정 | 반이라는 개념이 없다. 예약 시스템에 가까워진다 |

- [ ] 우리 학원의 관리 단위는 반인가 강좌인가 개인 시간표인가
- [ ] 한 학생이 여러 반에 들어가는 경우가 있는가
- [ ] 형제 등록·재원생 할인처럼 학생끼리 묶이는 규칙이 있는가
- [ ] 반이 학기 중에 갈라지거나 합쳐지는 일이 있는가, 그때 기록은 어디로 가는가

> 반이 갈라질 때 출결과 수납 기록이 따라가지 않으면 그 학생의 이력이 끊깁니다. **반을 삭제하는 기능보다 반을 닫고 기록을 남기는 기능이 먼저 필요합니다.**

## 2. 교습비를 언제 무엇으로 받는지 표로 만든다

개발 전에 이 표가 채워져 있어야 견적이 정확해집니다.

| 확인 항목 | 왜 물어보는가 |
| --- | --- |
| 결제 주기 | 월 단위인가 기간 단위인가. 개강일 기준인가 등록일 기준인가 |
| 일할 계산 | 월 중간에 들어온 학생의 첫 달을 어떻게 계산하는가 |
| 기타경비 | 교재비·모의고사비·차량비를 교습비와 따로 걷는가 함께 걷는가 |
| 수납 수단 | 계좌이체·카드·현금영수증 중 무엇을 시스템이 기록하는가 |
| 미납 관리 | 며칠 지나면 미납으로 보고, 누구에게 어떻게 알리는가 |

- [ ] 교습비와 기타경비를 항목별로 나눠 기록할 것인가
- [ ] 일할 계산 규칙을 문장으로 적어 두었는가
- [ ] 카드 결제를 붙인다면 PG 계약 주체가 학원인지 확인했는가
- [ ] 현금영수증 발행을 시스템에서 할 것인가 따로 할 것인가
- [ ] 미납 알림을 자동으로 보낼 것인가, 보낸다면 몇 회까지인가

## 3. 환불 계산은 학원이 정하는 것이 아니다

**이 항목이 학원관리 프로그램에서 가장 자주 잘못 만들어지는 자리입니다.**

「학원의 설립·운영 및 과외교습에 관한 법률」 **제18조 제1항**은 학습자가 수강을 계속할 수 없는 경우, 또는 학원의 등록말소·교습소 폐지로 교습을 계속할 수 없는 경우에 **받은 교습비등을 반환**하도록 정합니다. 같은 조 제2항이 반환 사유와 반환 금액을 대통령령에 위임하고, **시행령 제18조와 별표 4**가 그 기준을 정해 두었습니다.

반환 사유는 셋입니다.

| 반환 사유 | 내용 |
| --- | --- |
| 학원 사정 | 학원의 등록이 말소되거나 교습정지명령을 받은 경우 |
| 격리 | 학습자가 학원으로부터 격리된 경우 |
| 본인 의사 | 학습자가 본인의 의사로 수강 또는 학습장소 사용을 포기한 경우 |

세 번째, 학생이 스스로 그만둔 경우의 반환 금액이 **교습기간에 따라 갈립니다.**

**교습기간이 1개월 이내인 경우** (독서실 제외)

| 시점 | 반환 금액 |
| --- | --- |
| 교습 시작 전 | 이미 납부한 교습비등의 **전액** |
| 총 교습시간의 1/3 경과 전 | 이미 납부한 교습비등의 **3분의 2** |
| 총 교습시간의 1/2 경과 전 | 이미 납부한 교습비등의 **2분의 1** |
| 총 교습시간의 1/2 경과 후 | **없음** |

**교습기간이 1개월을 초과하는 경우** — 반환 사유가 발생한 해당 월의 반환 대상 교습비등에, **나머지 월의 교습비등 전액을 합산한 금액**을 반환합니다.

기준이 **날짜가 아니라 총 교습시간**이라는 점을 놓치면 계산이 어긋납니다. 주 3회 반과 주 2회 반은 같은 날 그만둬도 경과 비율이 다릅니다.

- [ ] 환불 계산을 사람이 하는가 시스템이 하는가
- [ ] 총 교습시간을 반별로 관리하고 있는가 (없으면 1/3·1/2 판정을 못 한다)
- [ ] 교습기간 1개월 이내와 초과를 구분해 계산하는가
- [ ] 기타경비(교재비·모의고사비)의 반환 기준을 따로 정해 두었는가
- [ ] 원격교습을 함께 판다면 실제 수강분을 차감하는 계산이 들어가는가
- [ ] 환불 내역을 남겨 두는가 — 분쟁이 생기면 이 기록이 근거가 된다

> 반환 기준은 **게시 의무도 함께 걸립니다.** 시·도 조례가 교습비등 반환기준 게시표 서식을 두고 있으니 관할 교육지원청 서식을 확인하시기 바랍니다.

## 4. 출결을 무엇으로 찍고 누구에게 알릴지 정한다

| 방식 | 장점 | 실무에서 생기는 문제 |
| --- | --- | --- |
| 강사가 화면에서 체크 | 추가 장비가 없다 | 수업 시작 후에 찍혀 등원 시각이 부정확하다 |
| 태그·카드 리더 | 등·하원 시각이 정확하다 | 카드를 안 가져온 학생 처리 규칙이 필요하다 |
| 학생 휴대폰 | 장비가 없다 | 중등부는 휴대폰을 걷는 학원이 많아 안 맞는다 |

- [ ] 등원만 찍을 것인가 하원까지 찍을 것인가
- [ ] 지각·조퇴·결석의 기준 시간을 정했는가
- [ ] 결석했을 때 자동으로 알릴 것인가, 강사가 확인 후 보낼 것인가
- [ ] 보충 수업을 출결에서 어떻게 표기하는가
- [ ] 출결 데이터를 몇 년 보관할 것인가

## 5. 알림 발송 — 안내와 광고의 경계를 시스템에 그어 둔다

**학원은 이 조항에 매일 걸립니다.** 수업이 밤 9시 넘어 끝나는 학원이 많기 때문입니다.

「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 **제50조 제3항**은 **오후 9시부터 다음 날 오전 8시까지** 전자적 전송매체로 **영리목적의 광고성 정보**를 전송하려면 수신자에게서 **별도의 사전 동의**를 받도록 정합니다. 같은 조 제1항은 그 시간대와 무관하게 광고성 정보에 명시적 사전 동의를 요구하고, 제4항은 **전송자의 명칭과 연락처**를 명시하게 하며, 제7항은 수신동의·수신거부·철회의 **처리 결과를 알리도록** 합니다.

경계는 이렇습니다. 오늘 등원했다는 출결 알림이나 이번 달 교습비 수납 확인은 **이미 맺은 거래를 이행하는 안내**입니다. 여기에 **"겨울 특강 모집합니다" 한 줄을 붙이면 그 문자는 광고성 정보가 됩니다.** 밤 10시에 나가는 하원 알림에 특강 안내를 얹는 순간 제3항의 별도 동의 대상이 되는 것입니다.

- [ ] 안내 발송과 홍보 발송을 시스템에서 분리해 두었는가
- [ ] 홍보 발송에 수신동의 여부를 저장하고, 동의한 사람에게만 나가는가
- [ ] 야간(21시~08시) 홍보 발송을 시스템이 막는가
- [ ] 발송 문구에 학원 명칭과 연락처가 들어가는가
- [ ] 수신거부 처리 결과를 보호자에게 알리는 절차가 있는가
- [ ] 알림톡과 문자 중 무엇을 쓰고, 실패했을 때 어디로 대체 발송하는가

> 실무에서 가장 흔한 사고는 **템플릿 하나에 안내와 홍보를 같이 넣어 둔 것**입니다. 급할 때 그 템플릿으로 전체 발송을 돌리면 동의하지 않은 보호자에게, 그것도 야간에 광고가 나갑니다. **템플릿 단계에서 갈라 두어야 사람이 실수해도 막힙니다.**

## 6. 만 14세 미만 학생의 개인정보를 어떻게 받을지 정한다

「개인정보 보호법」 **제22조의2 제1항**은 만 14세 미만 아동의 개인정보를 처리하기 위해 동의를 받아야 할 때 **법정대리인의 동의를 받고, 법정대리인이 동의했는지를 확인**하도록 정합니다(2023년 3월 14일 신설, 같은 해 9월 15일 시행). 같은 조 제3항은 아동에게 고지할 때 **이해하기 쉬운 양식과 명확하고 알기 쉬운 언어**를 쓰도록 합니다.

초등부와 중등 저학년을 받는 학원이라면 상담 신청 화면과 학생 등록 화면이 그대로 이 조항의 대상입니다.

- [ ] 홈페이지 상담 신청에서 신청자가 학생인지 보호자인지 구분하는가
- [ ] 만 14세 미만이면 보호자 동의를 확인한 뒤 접수되는 흐름인가
- [ ] 동의를 받은 기록을 언제 받았는지와 함께 남기는가
- [ ] 수집 항목을 필요한 범위로 줄였는가 (학교·학년까지 받을 이유가 있는가)
- [ ] 퇴원한 학생의 정보를 언제 파기하는지 정해 두었는가
- [ ] 건강·알레르기 같은 정보를 받는다면 민감정보 처리 근거를 확인했는가

## 7. 강사 정보는 등록 사항과 붙어 있다

「학원법」 **제6조 제1항**은 학원 등록 신청서에 **강사명단**을 기재하게 하고, 교습과정·강사명단·교습비등이 **바뀌면 변경등록**을 하도록 정합니다. 프로그램에서 강사를 추가·삭제하는 것과 교육지원청에 신고하는 것은 별개의 일입니다.

- [ ] 강사 등록·퇴사 시 변경등록을 누가 챙기는지 정했는가
- [ ] 강사별 담당 반과 급여 계산 기준(시급·월급·비율제)이 정리돼 있는가
- [ ] 강사가 볼 수 있는 화면과 원장만 보는 화면을 나눴는가
- [ ] 퇴사한 강사의 계정을 즉시 막는 절차가 있는가

## 8. 홈페이지와 겹치는 지점을 확인한다

학원관리 프로그램만 도입해도 홈페이지 쪽 의무는 따로 남습니다. 「학원법」 **제15조**는 인터넷으로 학습자를 모집할 때 **등록번호, 등록한 명칭, 교습과정, 교습비등**을 표시하도록 정하고 있고, 홈페이지·네이버 플레이스·블로그·SNS가 모두 여기 들어갑니다.

교습비등은 교습비만이 아니라 **기타경비까지 합한 말**이라 월 수강료만 적으면 표시를 마친 것이 아닙니다.

- [ ] 홈페이지의 교습비 표시를 관리자 화면에서 직접 고칠 수 있는가
- [ ] 관리 프로그램의 금액과 홈페이지의 금액이 같은 데이터를 보는가
- [ ] 교습비 표가 이미지가 아니라 글자로 올라가 있는가
- [ ] 시간표와 잔여 자리를 홈페이지에서 보여줄 것인가

> 금액을 이미지로 올리면 검색엔진과 AI가 안의 글자를 읽지 못합니다. 같은 일을 하는데 하나는 의무 이행으로 끝나고, 하나는 **"○○동 중2 수학학원 수강료"로 검색한 학부모에게 걸리는 자산**이 됩니다.

## 9. 구축 방식을 비교한다

| 방식 | 맞는 경우 | 확인할 것 |
| --- | --- | --- |
| 무료·저가 SaaS | 출결과 알림만 필요하고 규모가 작다 | 환불 계산이 법정 기준을 따르는가. 데이터를 나중에 내려받을 수 있는가 |
| 유료 SaaS | 여러 지점, 표준 기능으로 충분하다 | 학생 수 기준 과금인가. 문자 비용이 별도인가 |
| 직접 제작 | 반 편성·수납 규칙이 우리 학원 특유하다 | 홈페이지와 같은 데이터를 쓸 수 있는가. 유지보수 주체가 누구인가 |

- [ ] 지금 쓰는 엑셀·수기 장부를 어떤 형태로 옮길 것인가
- [ ] 데이터 반출(내려받기) 방법을 계약 전에 확인했는가
- [ ] 문자·알림톡 비용을 누가 부담하고 단가가 얼마인가
- [ ] 원장 외에 관리자를 몇 명 둘 것인가

## 10. 도입 전 마지막 확인

- [ ] 관리 단위(반·강좌·개인 시간표)를 정했는가
- [ ] 교습비와 기타경비를 항목별로 나눠 기록하기로 했는가
- [ ] 환불 계산이 학원법 제18조와 시행령 별표 4 기준을 따르는가
- [ ] 총 교습시간을 반별로 관리하고 있는가
- [ ] 안내 발송과 홍보 발송을 시스템에서 분리했는가
- [ ] 야간 홍보 발송을 막는 장치가 있는가
- [ ] 만 14세 미만 학생의 보호자 동의 절차를 넣었는가
- [ ] 강사 변경 시 변경등록을 누가 챙길지 정했는가
- [ ] 홈페이지 교습비 표시와 관리 프로그램의 금액이 어긋나지 않는가

---

법령과 조례는 개정될 수 있습니다. 실제 적용 전에는 [국가법령정보센터](https://www.law.go.kr)에서 현행 조문을, 교습비등 반환기준 게시표와 시설 기준은 **관할 교육지원청**과 시·도 조례를 확인하시기 바랍니다. 학원 등록·교습소 신고 절차는 교육지원청마다 운영이 다를 수 있습니다.

반 편성과 수강신청, 출결·수납을 한 화면에서 관리하는 시스템 구성은 [학원관리 프로그램과 수강신청 시스템](https://hompynara.kr/program/class-scheduling.php)에 정리돼 있습니다. 구축 문의는 [홈피나라 상담](https://hompynara.kr/inquiry.php)으로 주십시오.
