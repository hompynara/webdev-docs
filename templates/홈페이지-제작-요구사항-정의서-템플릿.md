# 홈페이지 제작 요구사항 정의서 템플릿 (복사해서 쓰는 무료 양식)

> 만든 곳: 홈피나라(2003년부터 비즈니스 웹사이트·예약 프로그램 제작) · 최종 수정: 2026-07

제작을 맡기기 전에 "무엇을 만들지"를 글로 한 번 정리해 두면, 견적이 정확해지고 제작 기간이 눈에 띄게 줄어듭니다. 반대로 이 정리가 없으면 작업 중반에 "그건 얘기 안 했잖아요"가 반복되죠. 저희가 20년 넘게 제작하며 본 견적 분쟁은 대부분 여기, **요구사항이 말로만 오간 지점**에서 시작됐습니다.

이 문서는 그 정리를 대신 해 주는 양식입니다. 통째로 복사해서 빈칸만 채우면 됩니다. 모르는 항목은 비워 두셔도 괜찮습니다 — "아직 안 정했다"를 아는 것만으로도 제작사가 무엇을 먼저 물어야 할지 정해지거든요.

## 2. 이 사이트로 얻고 싶은 것

방문자가 사이트에서 **하길 바라는 단 하나의 행동**을 먼저 정하세요. 이게 흐릿하면 페이지가 백화점처럼 넓어지고, 정작 아무 행동도 안 일어납니다.

- 방문자가 해 주길 바라는 핵심 행동: (전화 / 예약 / 문의 폼 / 견적 요청 / 구매 / 자료 다운로드 …)

- 성공을 어떻게 판단할지: 예: "월 문의 20건", "예약 전환 5%"

## 3. 주요 방문자

- 누가 옵니까: (연령·성별·지역·직업 등 떠오르는 대로)
- 어떤 상황에서 검색합니까: 예: "밤에 아이 열이 나서 근처 소아과를 급히 찾는 부모"
- 무슨 말로 검색할 것 같습니까: 예: `역삼역 피부과`, `강남 임플란트 비용`
- PC와 모바일 비중 예상: 모바일이 8:2 이상인 업종이 많습니다. 화면 설계 우선순위가 여기서 갈립니다.

## 자주 빠뜨리는 것 (제작 현장에서 본 것들)

- **오픈 후 수정 권한.** 위 6번에서 짚었듯, 이걸 안 정하면 오픈하고 나서 유지보수 비용으로 부딪힙니다.
- **모바일 우선순위.** 방문자 대부분이 휴대폰으로 보는데 PC 화면부터 예쁘게 잡다가, 정작 중요한 모바일이 어색해지는 경우가 많습니다.
- **원고 주체.** "글은 알아서 채워 주시는 거죠?"와 "글은 주시는 거죠?"가 어긋나면 오픈이 몇 주씩 밀립니다.
- **검색 노출을 나중에 생각하기.** 다 만든 뒤에 SEO를 얹으면 구조를 다시 손봐야 합니다. 요구사항 단계에서 "검색에 떠야 한다"를 넣어 두면 처음부터 그렇게 설계됩니다.
